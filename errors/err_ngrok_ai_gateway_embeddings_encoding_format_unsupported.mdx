## ERR_NGROK_AI_GATEWAY_EMBEDDINGS_ENCODING_FORMAT_UNSUPPORTED
Model `MODELID` on provider `PROVIDERID` doesn't accept 'encoding_format'. Omit it or set it to 'float'.
