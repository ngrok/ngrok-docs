## What does ERR_NGROK_10106 mean?

ngrok returns ERR_NGROK_10106 with this message:

```text
Signup domain requests aren't available right now. Contact ngrok support at support@ngrok.com to request your domain.
```




## Where can I get more help with ERR_NGROK_10106?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_10106) and include the error code.
