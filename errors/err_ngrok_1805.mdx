## What does ERR_NGROK_1805 mean?

ngrok returns ERR_NGROK_1805 with this message:

```text
Only Pay-as-you-go accounts with the Account Governance add-on can use dashboard IP restrictions.
Your account is not authorized to use dashboard IP restrictions.  

Upgrade to a Pay-as-you-go plan with the Account Governance add-on at: https://dashboard.ngrok.com/billing/choose-a-plan?plan=paygo
```
