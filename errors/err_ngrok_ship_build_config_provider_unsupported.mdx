## ERR_NGROK_SHIP_BUILD_CONFIG_PROVIDER_UNSUPPORTED

{/* vale off */}
Build provider `PROVIDER` is not supported. Allowed: 'dockerfile' and 'automatic'.
{/* vale on */}
