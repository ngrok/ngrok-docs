## What does ERR_NGROK_1106 mean?

ngrok returns ERR_NGROK_1106 with this message:

```text
Could not find <USER> API version. Use <VERSION> as user when connecting with SSH to get the latest version.
```




## Where can I get more help with ERR_NGROK_1106?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_1106) and include the error code.
