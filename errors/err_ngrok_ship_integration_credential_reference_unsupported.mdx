## What does ERR_NGROK_SHIP_INTEGRATION_CREDENTIAL_REFERENCE_UNSUPPORTED mean?

ngrok returns ERR_NGROK_SHIP_INTEGRATION_CREDENTIAL_REFERENCE_UNSUPPORTED with this message:

```text
Provider <PROVIDERID> needs <COUNT> credential values (<FIELDS>). A 'static_token_reference' holds one. Send them in 'static_token_value'.
```
