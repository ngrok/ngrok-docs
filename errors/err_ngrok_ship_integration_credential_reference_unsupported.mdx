## ERR_NGROK_SHIP_INTEGRATION_CREDENTIAL_REFERENCE_UNSUPPORTED
Provider `PROVIDERID` needs `COUNT` credential values (`FIELDS`). A 'static_token_reference' holds one. Send them in 'static_token_value'.
