## What does ERR_NGROK_300 mean?

ngrok returns ERR_NGROK_300 with this message:

```text
The authtoken credential <ID> has been revoked
and is no longer valid.
```




## Where can I get more help with ERR_NGROK_300?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_300) and include the error code.
