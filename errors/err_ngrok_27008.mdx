## What does ERR_NGROK_27008 mean?

ngrok returns ERR_NGROK_27008 with this message:

```text
This API key is scoped to a different gateway. Each key can only be used with the endpoint it was created for. Check the key's endpoint in the dashboard or create a new key for this gateway.
```
