## What does ERR_NGROK_312 mean?

ngrok returns ERR_NGROK_312 with this message:

```text
Failed to create a TLS endpoint for the account <ACCOUNT>.
Only Pay-as-you-go plans may create TLS endpoints.
This account is on the <PLAN> plan.

Upgrade to a Pay-as-you-go plan at: https://dashboard.ngrok.com/billing/choose-a-plan?plan=paygo
```
