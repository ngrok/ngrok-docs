## What does ERR_NGROK_AGENT_OWNER_MISMATCH mean?

ngrok returns ERR_NGROK_AGENT_OWNER_MISMATCH with this message:

```text
Agent <ID> is owned by <OWNER>. Log in as that principal, or run 'ngrok agent register --new'.
```
