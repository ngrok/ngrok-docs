## What does ERR_NGROK_221 mean?

ngrok returns ERR_NGROK_221 with this message:

```text
This is a valid API token, but the account <ACCOUNT> is not authorized to submit or view abuse reports. Email support@ngrok.com if you believe this is an error.
```




## Where can I get more help with ERR_NGROK_221?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_221) and include the error code.
