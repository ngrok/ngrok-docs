## ERR_NGROK_SHIP_GATEWAY_CONFIG_UNSUPPORTED

{/* vale off */}
A `SCHEME` endpoint can't use these gateway settings: `SETTINGS`. Remove them, or use an https:// URL.
{/* vale on */}
