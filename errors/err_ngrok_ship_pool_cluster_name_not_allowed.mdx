## What does ERR_NGROK_SHIP_POOL_CLUSTER_NAME_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_SHIP_POOL_CLUSTER_NAME_NOT_ALLOWED with this message:

```text
The 'cluster_name' field must be empty for an 'aws_ecs_managed' pool. ngrok names the cluster after the pool ID.
```
