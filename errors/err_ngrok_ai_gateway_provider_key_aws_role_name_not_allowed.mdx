## What does ERR_NGROK_AI_GATEWAY_PROVIDER_KEY_AWS_ROLE_NAME_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_AI_GATEWAY_PROVIDER_KEY_AWS_ROLE_NAME_NOT_ALLOWED with this message:

```text
The role in 'aws.roleArn' has a name that doesn't start with 'ngrok-ai-gateway-', or it has a path. ngrok can assume only a role with that name prefix and no path.
```
