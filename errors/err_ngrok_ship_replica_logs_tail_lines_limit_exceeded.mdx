## ERR_NGROK_SHIP_REPLICA_LOGS_TAIL_LINES_LIMIT_EXCEEDED

{/* vale off */}
The 'tail_lines' value `TAILLINES` must not exceed the 'limit' value `LIMIT`.
{/* vale on */}
