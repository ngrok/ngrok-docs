## What does ERR_NGROK_SHIP_ENVIRONMENT_POOL_CONFIG_SECTION_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_SHIP_ENVIRONMENT_POOL_CONFIG_SECTION_NOT_ALLOWED with this message:

```text
The <SECTION> settings do not match pool <ID>, which is a <KIND> pool. Remove the section, or set the settings for that pool kind.
```
