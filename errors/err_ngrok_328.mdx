## What does ERR_NGROK_328 mean?

ngrok returns ERR_NGROK_328 with this message:

```text
Domain part <PART> has an invalid first character. Valid domain parts must begin with a-z, A-Z, 0-9 or *. Failed to create an endpoint with the domain <DOMAIN>.
```
