## What does ERR_NGROK_26001 mean?

ngrok returns ERR_NGROK_26001 with this message:

```text
CAA records for domain <DOMAIN> found at <FOUNDAT> contain an accounturi parameter restriction (<ACCOUNTURI>). This restriction cannot be validated for managed certificates.
```
