## What does ERR_NGROK_3502 mean?

ngrok returns ERR_NGROK_3502 with this message:

```text
The forward-internal action can't forward between endpoints that use different protocols. This endpoint uses <PARENTPROTO>, and the endpoint you're forwarding to uses <TARGETPROTO>.
```
