## What does ERR_NGROK_AI_GATEWAY_PROVIDER_KEY_AWS_ROLE_ARN_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_AI_GATEWAY_PROVIDER_KEY_AWS_ROLE_ARN_NOT_ALLOWED with this message:

```text
Provider key <ID> holds an API key, so it can't take 'aws.roleArn'. Create a Bedrock key without 'value' to use an IAM role.
```
