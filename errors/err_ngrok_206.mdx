## What does ERR_NGROK_206 mean?

ngrok returns ERR_NGROK_206 with this message:

```text
The authentication you specified is actually an authtoken. Check your records for an API key. API keys and instructions are available on your dashboard: https://dashboard.ngrok.com/api-keys
```
