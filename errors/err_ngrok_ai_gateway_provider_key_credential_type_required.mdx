## What does ERR_NGROK_AI_GATEWAY_PROVIDER_KEY_CREDENTIAL_TYPE_REQUIRED mean?

ngrok returns ERR_NGROK_AI_GATEWAY_PROVIDER_KEY_CREDENTIAL_TYPE_REQUIRED with this message:

```text
The value field holds a Google service account key. Create a provider key with credentialType 'google_service_account' for it.
```
