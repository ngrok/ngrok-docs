## ERR_NGROK_SHIP_DOCKERFILE_READ_REFUSED

{/* vale off */}
GitHub refused to read Dockerfile `PATH` from branch `BRANCH` (HTTP `STATUS`). Check the ngrok GitHub app's access to the repository.
{/* vale on */}
