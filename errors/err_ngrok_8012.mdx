## What does ERR_NGROK_8012 mean?

ngrok returns ERR_NGROK_8012 with this message:

```text
Traffic successfully made it to the ngrok agent, but the agent failed to establish a connection to the upstream web service at <ADDR>.
```



## Why does ngrok return ERR_NGROK_8012?

This error occurs when the ngrok agent successfully receives traffic but fails to establish a connection with your local service (the "upstream" service). While the tunnel is created successfully, ngrok cannot forward the traffic to your application. This can happen with a Agent Endpoint or when using a Cloud Endpoint that forwards traffic to an agent.

## How do I fix ERR_NGROK_8012?

1. **Local Service Not Running or Inaccessible**

   **Cause:** The web service or application on your local machine is not active or cannot be reached.

   **Resolution:**
   - Start your local service. If you don't have a local service to try with
		 ngrok, see the [quickstart](/gateway/endpoints/agent-cli-quickstart#3-start-your-app-or-service),
		 for minimal apps in JavaScript, Go, and Python that work on port `8080`.
	 - Confirm you can access it directly (for example, `http://localhost:8080`).
   - Restart ngrok with the correct port number.

2. **Incorrect Port Specified**

   **Cause:** The port in your ngrok command doesn't match your local service's port.

   **Resolution:**
   - Verify the port your local service is using.
   - Update your ngrok command to use the correct port.
   - Example: Use `ngrok http 3000` if your service runs on port 3000.

### General troubleshooting steps

1. Verify local service accessibility without ngrok.
2. Ensure the latest ngrok version is installed.
3. Restart the ngrok agent.

## How do I prevent ERR_NGROK_8012?

1. Use a Cloud Endpoint with a Traffic Policy to provide a better user experience. Instead of showing an error, you can detect the connection failure and serve a custom maintenance page. [Learn more about Cloud Endpoints and Traffic Policy](/gateway/endpoints/cloud-endpoints/)

2. Use Endpoint Pooling to achieve high availability. By load balancing across multiple agents, traffic is automatically routed away from any agent experiencing this error, preventing any impact on your users. [Learn more about Endpoint Pooling](/gateway/endpoints/endpoint-pooling/)
