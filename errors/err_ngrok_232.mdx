## ERR_NGROK_232

{/* vale off */}
The request must specify only a single value for the `NAME` parameter but got `COUNT`: `VALUES`. Check your API client implementation and review the API documentation: https://ngrok.com/docs/api-reference/.
{/* vale on */}
