## What does ERR_NGROK_PRIVATE_LINK_HOSTNAME_INVALID mean?

ngrok returns ERR_NGROK_PRIVATE_LINK_HOSTNAME_INVALID with this message:

```text
Hostname <HOSTNAME> is not a valid DNS name. Each label must be 1 to 63 letters, digits, or '-', and must not start or end with '-'. Only the first label can be '*'.
```
