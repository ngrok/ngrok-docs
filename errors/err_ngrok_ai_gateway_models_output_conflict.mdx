## ERR_NGROK_AI_GATEWAY_MODELS_OUTPUT_CONFLICT

{/* vale off */}
`MODEL` bills per `UNIT`, so the request can fail over only between models that return the same outputs. It returns `OUTPUTS`, but `OTHERMODEL` returns `OTHEROUTPUTS`.
{/* vale on */}
