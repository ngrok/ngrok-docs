## ERR_NGROK_27250
ngrok doesn't store interactions yet, so "store" can't be true. Omit it or set it to false to send a stateless request.

If you're having trouble resolving this error, please reach out to [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_27250)
