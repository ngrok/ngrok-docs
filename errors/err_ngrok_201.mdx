## What does ERR_NGROK_201 mean?

ngrok returns ERR_NGROK_201 with this message:

```text
The ngrok API requires that you use Basic or Bearer authentication via the Authorization header. It could not parse the header in this request. API keys and instructions are available on your dashboard: https://dashboard.ngrok.com/api-keys
```
