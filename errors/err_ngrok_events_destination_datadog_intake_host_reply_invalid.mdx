## What does ERR_NGROK_EVENTS_DESTINATION_DATADOG_INTAKE_HOST_REPLY_INVALID mean?

ngrok returns ERR_NGROK_EVENTS_DESTINATION_DATADOG_INTAKE_HOST_REPLY_INVALID with this message:

```text
The Datadog intake_host accepted the test event, but its reply is not valid JSON. Make sure the host serves the Datadog logs API at '/api/v2/logs', after any path prefix in the intake_host.
```
