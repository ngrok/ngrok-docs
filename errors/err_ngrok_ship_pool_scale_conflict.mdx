## What does ERR_NGROK_SHIP_POOL_SCALE_CONFLICT mean?

ngrok returns ERR_NGROK_SHIP_POOL_SCALE_CONFLICT with this message:

```text
The compute pool changed while this request ran. Read the pool again, then retry.
```
