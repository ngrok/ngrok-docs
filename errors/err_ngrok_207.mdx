## ERR_NGROK_207

{/* vale off */}
The authentication you specified is actually an authtoken, not an API key token. Your key: `TOKEN`. Check your records for an API key with the form FIRSTPART_SECONDPART. API keys and instructions are available on your dashboard: https://dashboard.ngrok.com/api-keys
{/* vale on */}
