## What does ERR_NGROK_2266 mean?

ngrok returns ERR_NGROK_2266 with this message:

```text
Traffic policy contains more than one AI Gateway Action. Only one AI Gateway action is allowed per traffic policy.
```




## Where can I get more help with ERR_NGROK_2266?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_2266) and include the error code.
