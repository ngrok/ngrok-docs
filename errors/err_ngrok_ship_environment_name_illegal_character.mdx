## ERR_NGROK_SHIP_ENVIRONMENT_NAME_ILLEGAL_CHARACTER

{/* vale off */}
Environment name `NAME` contains the illegal character `CHAR`. Allowed: lowercase letters, digits, '-', and '_'.
{/* vale on */}
