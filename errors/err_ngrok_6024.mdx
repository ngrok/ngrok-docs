## What does ERR_NGROK_6024 mean?

ngrok returns ERR_NGROK_6024 with this message:

```text
You are about to visit <HOSTPORT><SERVEDBYSTR>. This website is served for free through ngrok.com. You should only visit this website if you trust whoever sent the link to you.
```



## Why does ngrok return ERR_NGROK_6024?

ngrok displays this page to prevent abuse. Visitors to your site will only see it once.
If you are attempting to access an endpoint programmatically and are still encountering this error, the interstitial page can be bypassed.

## How do I fix ERR_NGROK_6024?

- Set and send an ngrok-skip-browser-warning request header with any value.
- Or, set and send a custom/non-standard browser User-Agent request header.
- Or, please [upgrade](https://dashboard.ngrok.com/billing) to any paid ngrok account.

For more information and examples, please see the interstitial explanation [here](/pricing-limits/free-plan-limits#removing-the-interstitial-page).

If you are the administrator for this account, and none of these steps work for you or you have more questions, email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_6024).


## Where can I get more help with ERR_NGROK_6024?
