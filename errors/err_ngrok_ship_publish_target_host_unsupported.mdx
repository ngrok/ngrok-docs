## ERR_NGROK_SHIP_PUBLISH_TARGET_HOST_UNSUPPORTED

{/* vale off */}
A `KIND` publish target always publishes to `FIXEDHOST`. The 'host' value `HOST` is not allowed.
{/* vale on */}
