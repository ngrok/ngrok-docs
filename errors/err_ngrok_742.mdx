## What does ERR_NGROK_742 mean?

ngrok returns ERR_NGROK_742 with this message:

```text
This server is draining connections and cannot accept new ones. Please reconnect to continue.
```




## Where can I get more help with ERR_NGROK_742?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_742) and include the error code.
