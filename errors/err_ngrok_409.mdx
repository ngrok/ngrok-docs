## What does ERR_NGROK_409 mean?

ngrok returns ERR_NGROK_409 with this message:

```text
Domain has an invalid character sequence. Valid domains may not contain repeated periods '..'. Failed to reserve <DOMAIN>.
```




## Where can I get more help with ERR_NGROK_409?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_409) and include the error code.
