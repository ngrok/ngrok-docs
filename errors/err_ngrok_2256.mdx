## What does ERR_NGROK_2256 mean?

ngrok returns ERR_NGROK_2256 with this message:

```text
The action <ACTION> is not available for your current plan. Upgrade to <PLANS> to use this action.
```




## Where can I get more help with ERR_NGROK_2256?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_2256) and include the error code.
