## What does ERR_NGROK_200 mean?

ngrok returns ERR_NGROK_200 with this message:

```text
The ngrok API requires that you set the Authorization header for authentication. Your API keys and instructions are available on your dashboard: https://dashboard.ngrok.com/api-keys
```
