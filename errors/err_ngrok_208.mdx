## What does ERR_NGROK_208 mean?

ngrok returns ERR_NGROK_208 with this message:

```text
The authentication you specified is actually an API key ID, not an API key token. Your credential: <TOKEN>. Check your records for an API key with the form FIRSTPART_SECONDPART. API keys and instructions are available on your dashboard: https://dashboard.ngrok.com/api-keys
```
