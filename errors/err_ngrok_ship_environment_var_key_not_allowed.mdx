## What does ERR_NGROK_SHIP_ENVIRONMENT_VAR_KEY_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_SHIP_ENVIRONMENT_VAR_KEY_NOT_ALLOWED with this message:

```text
Environment variable <KEY> is reserved. ngrok sets 'PORT' and the 'PORT_' variables from the endpoint templates.
```
