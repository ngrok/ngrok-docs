## ERR_NGROK_SHIP_ENVIRONMENT_VAR_KEY_NOT_ALLOWED

{/* vale off */}
Environment variable `KEY` is reserved. ngrok sets 'PORT' and the 'PORT_' variables from the endpoint templates.
{/* vale on */}
