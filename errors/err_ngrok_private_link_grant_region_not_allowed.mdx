## What does ERR_NGROK_PRIVATE_LINK_GRANT_REGION_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_PRIVATE_LINK_GRANT_REGION_NOT_ALLOWED with this message:

```text
This private link does not cover the VPC endpoint's AWS region. Add the region to the link's 'regions' first.
```
