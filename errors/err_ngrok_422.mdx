## What does ERR_NGROK_422 mean?

ngrok returns ERR_NGROK_422 with this message:

```text
The reserved domain name update failed because no values were provided. Specify at least one value.
```




## Where can I get more help with ERR_NGROK_422?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_422) and include the error code.
