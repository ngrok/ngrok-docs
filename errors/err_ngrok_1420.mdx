## What does ERR_NGROK_1420 mean?

ngrok returns ERR_NGROK_1420 with this message:

```text
Cannot delete IP Policy (<POLICYID>) because it is referenced by one or more IP Restrictions: (<RESTRICTIONIDS>). Detach this IP Policy from all IP Restrictions before deleting it.
```
