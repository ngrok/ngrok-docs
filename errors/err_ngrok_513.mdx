## What does ERR_NGROK_513 mean?

ngrok returns ERR_NGROK_513 with this message:

```text
The domain <DOMAIN> is not a valid DNS name. No domain part may be more than 63 characters long.
```




## Where can I get more help with ERR_NGROK_513?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_513) and include the error code.
