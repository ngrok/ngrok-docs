## What does ERR_NGROK_3105 mean?

ngrok returns ERR_NGROK_3105 with this message:

```text
You lack the required permission to use this site.

Contact the owner to obtain permission and then refresh this page.
```




## Where can I get more help with ERR_NGROK_3105?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_3105) and include the error code.
