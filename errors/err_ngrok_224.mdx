## What does ERR_NGROK_224 mean?

ngrok returns ERR_NGROK_224 with this message:

```text
The value <VAL> is not valid for the terminate_at property of the TLS Termination endpoint configuration module. Must be either 'edge', 'agent' or 'upstream'.
```
