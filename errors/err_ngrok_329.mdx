## What does ERR_NGROK_329 mean?

ngrok returns ERR_NGROK_329 with this message:

```text
Domain part <PART> has an invalid last character. Valid domains must end with a-z A-Z or 0-9. Failed to create an endpoint with the domain <DOMAIN>.
```
