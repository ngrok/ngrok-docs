## What does ERR_NGROK_1806 mean?

ngrok returns ERR_NGROK_1806 with this message:

```text
Only Pay-as-you-go accounts with the Account Governance add-on can use API IP restrictions.
Your account is not authorized to use API IP restrictions.  

Upgrade to a Pay-as-you-go plan with the Account Governance add-on at: https://dashboard.ngrok.com/billing/choose-a-plan?plan=paygo
```
