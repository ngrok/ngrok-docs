## What does ERR_NGROK_1423 mean?

ngrok returns ERR_NGROK_1423 with this message:

```text
An action should now be specified on the IP Policy Rule, not IP Policy. Contact ngrok support if you need additional time to migrate.
```




## Where can I get more help with ERR_NGROK_1423?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_1423) and include the error code.
