## What does ERR_NGROK_4302 mean?

ngrok returns ERR_NGROK_4302 with this message:

```text
Unable to redeem password: <REASON>
```



## Why does ngrok return ERR_NGROK_4302?

Your password is unable to be redeemed because it has expired.

## How do I fix ERR_NGROK_4302?

Reset your password from the dashboard [login page](https://dashboard.ngrok.com/login), then click the link in the password reset email before the link expires.

If you still have issues, contact [support@ngrok.com](mailto:support@ngrok.com).


## Where can I get more help with ERR_NGROK_4302?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_4302) and include the error code.
