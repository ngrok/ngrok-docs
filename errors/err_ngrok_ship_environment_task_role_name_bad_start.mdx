## ERR_NGROK_SHIP_ENVIRONMENT_TASK_ROLE_NAME_BAD_START

{/* vale off */}
The 'task_role_arn' value must have 'ngrok-ship-task-' directly after 'role/', with no path before it. IAM roles cannot be renamed, so create a role with that name.
{/* vale on */}
