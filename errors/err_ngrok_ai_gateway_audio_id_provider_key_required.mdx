## ERR_NGROK_AI_GATEWAY_AUDIO_ID_PROVIDER_KEY_REQUIRED

{/* vale off */}
Audio ID `AUDIOID` did not come from ngrok, so only your own provider key can use it. Add a provider key, or send an audio ID from an earlier response.
{/* vale on */}
