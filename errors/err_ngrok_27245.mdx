## What does ERR_NGROK_27245 mean?

ngrok returns ERR_NGROK_27245 with this message:

```text
The Files API cannot apply "<PARAMETER>" to a listing served by an ngrok-managed key for provider "<PROVIDERID>". Drop the parameter, or add your own provider key.
```
