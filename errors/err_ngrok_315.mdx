## What does ERR_NGROK_315 mean?

ngrok returns ERR_NGROK_315 with this message:

```text
Wildcard domains are a feature reserved for ngrok's Pay-as-you-go plan.
Failed to create an endpoint with the wildcard domain <DOMAIN> for the account <ACCOUNT>.
This account is on the <PLAN> plan.

Upgrade to a Pay-as-you-go plan at: https://dashboard.ngrok.com/billing/choose-a-plan?plan=paygo
```
