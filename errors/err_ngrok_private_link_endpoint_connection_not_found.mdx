## What does ERR_NGROK_PRIVATE_LINK_ENDPOINT_CONNECTION_NOT_FOUND mean?

ngrok returns ERR_NGROK_PRIVATE_LINK_ENDPOINT_CONNECTION_NOT_FOUND with this message:

```text
AWS reports no connection from VPC endpoint <VPCE_ID> in <AWS_REGION>. Create the endpoint in that region, or set 'aws_region' to the endpoint's region.
```
