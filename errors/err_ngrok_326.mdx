## What does ERR_NGROK_326 mean?

ngrok returns ERR_NGROK_326 with this message:

```text
Invalid character <CHAR> in domain name. Valid domains may contain only a-z, A-Z, 0-9, . * and - characters. Failed to create an endpoint with the domain <DOMAIN>.
```
