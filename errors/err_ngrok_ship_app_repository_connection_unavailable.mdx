## What does ERR_NGROK_SHIP_APP_REPOSITORY_CONNECTION_UNAVAILABLE mean?

ngrok returns ERR_NGROK_SHIP_APP_REPOSITORY_CONNECTION_UNAVAILABLE with this message:

```text
The ngrok GitHub app is <STATE> for this repository. Reinstall or reactivate it on GitHub.
```
