## What does ERR_NGROK_1123 mean?

ngrok returns ERR_NGROK_1123 with this message:

```text
Tunnel '-proxy-proto=<PROXYPROTO> specifies invalid protocol version.
Use one of version '1' or '2' to enable proxy proto.
```
