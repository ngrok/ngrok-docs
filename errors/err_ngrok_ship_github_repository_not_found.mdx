## ERR_NGROK_SHIP_GITHUB_REPOSITORY_NOT_FOUND
Repository `REPO` was not found on GitHub, or the ngrok GitHub app has no access to it.

If you're having trouble resolving this error, please reach out to [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_SHIP_GITHUB_REPOSITORY_NOT_FOUND)
