## What does ERR_NGROK_335 mean?

ngrok returns ERR_NGROK_335 with this message:

```text
The bind cookie you specified is malformed. This usually indicates a bug in the client's protocol implementation.
```




## Where can I get more help with ERR_NGROK_335?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_335) and include the error code.
