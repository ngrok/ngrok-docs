## What does ERR_NGROK_129 mean?

ngrok returns ERR_NGROK_129 with this message:

```text
Agent <ID> already has an active session. Stop the other agent that uses this ID, or register this host as a new agent.
```

Troubleshoot ERR_NGROK_129 with your AI agent.

</Tip>
