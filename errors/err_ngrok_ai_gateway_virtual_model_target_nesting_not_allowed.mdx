## ERR_NGROK_AI_GATEWAY_VIRTUAL_MODEL_TARGET_NESTING_NOT_ALLOWED

{/* vale off */}
`TARGET` is a virtual model. Virtual models can't point to other virtual models.
{/* vale on */}
