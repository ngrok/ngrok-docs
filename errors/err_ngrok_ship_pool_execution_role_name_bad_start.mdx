## ERR_NGROK_SHIP_POOL_EXECUTION_ROLE_NAME_BAD_START

{/* vale off */}
The 'execution_role_arn' role name `NAME` must start with 'ngrok-ship-'. The recommended permissions policy grants iam:PassRole only on that prefix.
{/* vale on */}
