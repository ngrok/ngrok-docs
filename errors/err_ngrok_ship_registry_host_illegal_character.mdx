## ERR_NGROK_SHIP_REGISTRY_HOST_ILLEGAL_CHARACTER

{/* vale off */}
The 'host' value `HOST` contains the illegal character `CHAR`. Use a hostname with an optional port, and no scheme or path.
{/* vale on */}
