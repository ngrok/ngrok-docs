## What does ERR_NGROK_18024 mean?

ngrok returns ERR_NGROK_18024 with this message:

```text
AI Gateway has moved to https://app.ngrok.ai. This API only allows managing existing legacy gateways.
```

<Tip>
Troubleshoot ERR_NGROK_18024 with your AI agent.
Connect it to the [ngrok MCP server](/mcp-server), then ask what caused the error and how to fix it.
</Tip>
