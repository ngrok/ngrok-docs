## What does ERR_NGROK_1413 mean?

ngrok returns ERR_NGROK_1413 with this message:

```text
IP Policy Rule is missing a network mask. Consider using <IP>/<BITS> if you want to target a single host IP.
```

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_1413) and include the error code.
