## What does ERR_NGROK_AI_GATEWAY_BEDROCK_ROLE_KEY_MODEL_UNSUPPORTED mean?

ngrok returns ERR_NGROK_AI_GATEWAY_BEDROCK_ROLE_KEY_MODEL_UNSUPPORTED with this message:

```text
Model <MODELID> runs on the Bedrock OpenAI-compatible endpoint, and a Bedrock key with an IAM role can't call it. Add a Bedrock API key to use the model.
```
