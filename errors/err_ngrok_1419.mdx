## What does ERR_NGROK_1419 mean?

ngrok returns ERR_NGROK_1419 with this message:

```text
Cannot delete only rule (<RULEID>) in use by dashboard IP Restriction (<RESTRICTIONID>). Detach this IP Policy from IP Restriction before deleting this rule.
```
