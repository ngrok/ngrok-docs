## What does ERR_NGROK_EVENTS_DESTINATION_DATADOG_INTAKE_HOST_REFUSED mean?

ngrok returns ERR_NGROK_EVENTS_DESTINATION_DATADOG_INTAKE_HOST_REFUSED with this message:

```text
The Datadog intake_host refused the test event with HTTP status <STATUS>. Make sure the host accepts Datadog logs API requests at '/api/v2/logs', after any path prefix in the intake_host.
```
