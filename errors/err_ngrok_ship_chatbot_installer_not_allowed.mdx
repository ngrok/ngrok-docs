## What does ERR_NGROK_SHIP_CHATBOT_INSTALLER_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_SHIP_CHATBOT_INSTALLER_NOT_ALLOWED with this message:

```text
Only a Slack workspace admin or owner can connect ngrok to this workspace. Ask an admin to reconnect the Slack integration, then try again.
```
