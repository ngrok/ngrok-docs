## ERR_NGROK_SHIP_CHATBOT_INSTALLER_NOT_ALLOWED

{/* vale off */}
Only a Slack workspace admin or owner can connect ngrok to this workspace. Ask an admin to reconnect the Slack integration, then try again.
{/* vale on */}
