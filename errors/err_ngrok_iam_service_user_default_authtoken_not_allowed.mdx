## What does ERR_NGROK_IAM_SERVICE_USER_DEFAULT_AUTHTOKEN_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_IAM_SERVICE_USER_DEFAULT_AUTHTOKEN_NOT_ALLOWED with this message:

```text
A service user can't have a default authtoken. Membership <ID> belongs to a service user.
```
