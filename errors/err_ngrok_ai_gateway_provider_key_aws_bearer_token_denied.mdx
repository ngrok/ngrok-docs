## What does ERR_NGROK_AI_GATEWAY_PROVIDER_KEY_AWS_BEARER_TOKEN_DENIED mean?

ngrok returns ERR_NGROK_AI_GATEWAY_PROVIDER_KEY_AWS_BEARER_TOKEN_DENIED with this message:

```text
Bedrock refused the API key that ngrok made from the role in 'aws.roleArn'. Allow bedrock:CallWithBearerToken in the policy of the role.
```
