## ERR_NGROK_SHIP_INTEGRATION_CREDENTIAL_INPUT_UNSUPPORTED

{/* vale off */}
Provider `PROVIDERID` does not take a `INPUT` credential. It takes `EXPECTED`.
{/* vale on */}
