## ERR_NGROK_SHIP_PUBLISH_TARGET_DOCKER_HUB_REPOSITORY_REFUSED
Docker Hub refused to create repository `REPOSITORY` (HTTP `STATUS`). Check that the push credential can write to namespace `NAMESPACE`.
