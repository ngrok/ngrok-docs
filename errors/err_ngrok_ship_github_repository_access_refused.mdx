## ERR_NGROK_SHIP_GITHUB_REPOSITORY_ACCESS_REFUSED
GitHub refused the ngrok GitHub app's request for repository `REPO` (HTTP 403). Check the app's permissions and repository access.




## Further help
If you're having trouble resolving this error, please reach out to [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_SHIP_GITHUB_REPOSITORY_ACCESS_REFUSED)
