## What does ERR_NGROK_5512 mean?

ngrok returns ERR_NGROK_5512 with this message:

```text
Email is malformed. Email "<EMAIL>" is missing an @ sign.
```




## Where can I get more help with ERR_NGROK_5512?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_5512) and include the error code.
