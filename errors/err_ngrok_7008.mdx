## What does ERR_NGROK_7008 mean?

ngrok returns ERR_NGROK_7008 with this message:

```text
Edges are deprecated and no longer available.
If you have used edges before, a migration guide is available: https://ngrok.com/docs/gateway/edges/#migration-guide.

If you have lost access to actively running edges, this is an error, please contact support@ngrok.com for help.
```
