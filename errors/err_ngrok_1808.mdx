## What does ERR_NGROK_1808 mean?

ngrok returns ERR_NGROK_1808 with this message:

```text
Only Pay-as-you-go accounts with the Account Governance add-on can use endpoints IP restrictions.
Your account is not authorized to use endpoints IP restrictions.  

Upgrade to a Pay-as-you-go plan with the Account Governance add-on at: https://dashboard.ngrok.com/billing/choose-a-plan?plan=paygo
```
