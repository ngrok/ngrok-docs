## What does ERR_NGROK_511 mean?

ngrok returns ERR_NGROK_511 with this message:

```text
The domain <DOMAIN> has a dangling CNAME record. The CNAME must be deleted before this domain can be reserved.
```

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_511) and include the error code.
