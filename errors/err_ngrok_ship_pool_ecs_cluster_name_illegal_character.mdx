## What does ERR_NGROK_SHIP_POOL_ECS_CLUSTER_NAME_ILLEGAL_CHARACTER mean?

ngrok returns ERR_NGROK_SHIP_POOL_ECS_CLUSTER_NAME_ILLEGAL_CHARACTER with this message:

