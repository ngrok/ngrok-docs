## What does ERR_NGROK_AI_GATEWAY_PROVIDER_BASE_URL_LOOP_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_AI_GATEWAY_PROVIDER_BASE_URL_LOOP_NOT_ALLOWED with this message:

```text
The AI gateway received a request that it sent upstream, so the request loops. A custom provider's base URL must not lead to the AI gateway.
```
