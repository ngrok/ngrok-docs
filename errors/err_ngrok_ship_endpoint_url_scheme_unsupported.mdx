## ERR_NGROK_SHIP_ENDPOINT_URL_SCHEME_UNSUPPORTED

{/* vale off */}
The `FIELD` value `VALUE` uses the unsupported scheme `SCHEME`. Allowed: https://, tls://, or tcp://.
{/* vale on */}
