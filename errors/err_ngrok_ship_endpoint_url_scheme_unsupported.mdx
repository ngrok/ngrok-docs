## What does ERR_NGROK_SHIP_ENDPOINT_URL_SCHEME_UNSUPPORTED mean?

ngrok returns ERR_NGROK_SHIP_ENDPOINT_URL_SCHEME_UNSUPPORTED with this message:

```text
The <FIELD> value <VALUE> uses the unsupported scheme <SCHEME>. Allowed: https://, tls://, or tcp://.
```
