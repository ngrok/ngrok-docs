## ERR_NGROK_SHIP_GITHUB_INSTALLATION_NOT_ALLOWED
Your GitHub user cannot see GitHub installation `INSTALLATIONID`. Configure the ngrok GitHub app's access, or reconnect GitHub.




## Further help
If you're having trouble resolving this error, please reach out to [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_SHIP_GITHUB_INSTALLATION_NOT_ALLOWED)
