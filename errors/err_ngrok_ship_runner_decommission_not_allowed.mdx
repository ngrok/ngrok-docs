## What does ERR_NGROK_SHIP_RUNNER_DECOMMISSION_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_SHIP_RUNNER_DECOMMISSION_NOT_ALLOWED with this message:

```text
Runner <ID> runs the whole compute pool, so it cannot be removed on its own. Delete the pool to remove it.
```
