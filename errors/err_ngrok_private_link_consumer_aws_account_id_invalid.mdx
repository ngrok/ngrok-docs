## What does ERR_NGROK_PRIVATE_LINK_CONSUMER_AWS_ACCOUNT_ID_INVALID mean?

ngrok returns ERR_NGROK_PRIVATE_LINK_CONSUMER_AWS_ACCOUNT_ID_INVALID with this message:

```text
The 'consumer_aws_account_id' value is not an AWS account ID. An AWS account ID is 12 digits.
```
