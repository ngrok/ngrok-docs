## What does ERR_NGROK_SHIP_POOL_LIFECYCLE_SCALE_NOT_ALLOWED mean?

ngrok returns ERR_NGROK_SHIP_POOL_LIFECYCLE_SCALE_NOT_ALLOWED with this message:

```text
The compute pool is <LIFECYCLE>. Node counts can change only while the pool is running.
```
