## What does ERR_NGROK_331 mean?

ngrok returns ERR_NGROK_331 with this message:

```text
You may not create an endpoint using a domain with the TLD <SUFFIX>. This TLD is not reachable over the public internet. Failed to create an endpoint with the domain <DOMAIN>.
```
