## What does ERR_NGROK_3115 mean?

ngrok returns ERR_NGROK_3115 with this message:

```text
The redirect_uri configured for this application is not properly configured or whitelisted with <PROVIDER>.

Contact the owner of this application in order to fix this error.
```
