## What does ERR_NGROK_417 mean?

ngrok returns ERR_NGROK_417 with this message:

```text
This wildcard domain would conflict with a domain reserved for another account. Failed to reserve <DOMAIN>.
```




## Where can I get more help with ERR_NGROK_417?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_417) and include the error code.
