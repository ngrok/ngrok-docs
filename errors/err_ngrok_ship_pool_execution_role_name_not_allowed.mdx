## ERR_NGROK_SHIP_POOL_EXECUTION_ROLE_NAME_NOT_ALLOWED

{/* vale off */}
The 'execution_role_arn' value must not have 'ngrok-ship-task-' directly after 'role/'. That prefix is for task roles.
{/* vale on */}
