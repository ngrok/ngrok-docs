## What does ERR_NGROK_462 mean?

ngrok returns ERR_NGROK_462 with this message:

```text
Region and IP resolution is not available for this domain. The DNS name <NAME> has records that ngrok does not manage.
```




## Where can I get more help with ERR_NGROK_462?

Email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_462) and include the error code.
