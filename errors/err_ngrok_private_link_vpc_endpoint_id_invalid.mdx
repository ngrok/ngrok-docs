## What does ERR_NGROK_PRIVATE_LINK_VPC_ENDPOINT_ID_INVALID mean?

ngrok returns ERR_NGROK_PRIVATE_LINK_VPC_ENDPOINT_ID_INVALID with this message:

```text
The 'vpc_endpoint_id' value is not a VPC endpoint ID. A VPC endpoint ID is 'vpce-' and lowercase hex digits, like 'vpce-0123abcd'.
```
