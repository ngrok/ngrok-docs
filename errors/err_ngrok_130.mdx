## What does ERR_NGROK_130 mean?

ngrok returns ERR_NGROK_130 with this message:

```text
The <ACCOUNT> account accepts only personal access tokens for agent sessions. This agent used a credential of type <CREDENTIALTYPE>. Use a personal access token instead, or ask an account admin to change the agent credential policy.
```
