## ERR_NGROK_SHIP_ENDPOINT_URL_PRIVATE_HOSTNAME_LABEL_LIMIT_EXCEEDED

{/* vale off */}
The `FIELD` hostname `HOST` has too many labels. Max `LIMIT` under this private suffix, got `GOT`. Use hyphens instead of dots.
{/* vale on */}
