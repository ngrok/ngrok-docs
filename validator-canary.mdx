---

Bad YAML syntax:

```yaml policy.yml
on_http_request:
  - actions:
      - type: deny
       config:
        status_code: 403
```

Rule without an actions list:

```yaml policy.yml
on_http_request:
  - type: deny
```

Action without a type:

```yaml policy.yml
on_tcp_connect:
  - actions:
      - config:
          url: tcp://example.internal:8000
```

Invalid JSON:

```json policy.json
{
  "on_http_request": [
    { "actions": [ { "type": "deny" } ] },
  ]
}
```
