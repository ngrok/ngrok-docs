[Moonshot AI](https://www.moonshot.ai) builds the Kimi family of models.

Moonshot AI supports Chat Completions requests.

<Note>
Moonshot AI is a **built-in provider** you can pay for with credits, so a provider key is optional.
Add your own Moonshot AI key to bill usage to your Moonshot AI account instead of your ngrok.ai credits.
</Note>

## Setup

<Steps>
  <Step title="Create an access key and add credits">
    Follow the [quickstart](/ai-gateway/quickstart) to create an access key and purchase [credits](/ai-gateway/concepts/credits) in [app.ngrok.ai](https://app.ngrok.ai).
  </Step>

  <Step title="Store your Moonshot AI API key (optional)">
    Skip this step to pay with credits.
    To bring your own key, create an API key in your [Moonshot AI](https://www.moonshot.ai) account. Then [add a provider key](/ai-gateway/guides/attaching-provider-keys#add-a-provider-key) and [create an access key configuration](/ai-gateway/guides/access-key-configurations#create-a-configuration) with a `moonshotai` routing rule that uses it.
  </Step>

  <Step title="Send requests">
    Send requests with your access key:

    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://gateway.ngrok.ai/v1",
        api_key="ng-xxxxx-g1-xxxxx",
    )

    response = client.chat.completions.create(
        model="moonshotai:kimi-k3",
        messages=[{"role": "user", "content": "Hello!"}]
    )
    ```

    QwenCloud and Tencent TokenHub also serve Kimi models, so the `moonshotai:` prefix keeps the request on Moonshot AI.
  </Step>
</Steps>
