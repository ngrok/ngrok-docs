title: Mistral AI

---

[Mistral AI](https://mistral.ai) serves its own models and open models from other labs through its API.

Mistral AI supports Chat Completions requests.

<Note>
Even though Mistral AI is a **built-in provider**, it still requires you to **bring your own key** because you can't pay for it with credits at this time.
</Note>

## Setup

<Steps>
  <Step title="Create an access key">
    Follow the [quickstart](/ai-gateway/quickstart) to create an access key in [app.ngrok.ai](https://app.ngrok.ai).
  </Step>

  <Step title="Store your Mistral AI API key">
    Create an API key in your [Mistral AI](https://mistral.ai) account. Then [add a provider key](/ai-gateway/guides/attaching-provider-keys#add-a-provider-key).
  </Step>

  <Step title="Create a configuration">
    [Create an access key configuration](/ai-gateway/guides/access-key-configurations#create-a-configuration) with a `mistral` routing rule and allow Mistral AI in the access scope.
  </Step>

  <Step title="Assign and send requests">
    Assign the configuration to your access key and send requests with your access key:

    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://gateway.ngrok.ai/v1",
        api_key="ng-xxxxx-g1-xxxxx",
    )

    response = client.chat.completions.create(
        model="mistral:z-ai/glm-5.3",
        messages=[{"role": "user", "content": "Hello!"}]
    )
    ```

    Other providers also serve GLM-5.3, so the `mistral:` prefix keeps the request on Mistral AI.
  </Step>
</Steps>

## Available models

See the [model catalog](/ai-gateway/reference/model-catalog#mistral-ai).
To call a Mistral AI model that isn't in the catalog yet, send its ID with the `mistral:` prefix. See [catalog updates](/ai-gateway/reference/model-catalog#catalog-updates).
