[MiniMax](https://www.minimax.io) builds the MiniMax M-series models.

MiniMax supports Chat Completions, Responses, and Anthropic Messages requests.

<Note>
MiniMax is a **built-in provider** you can pay for with credits, so a provider key is optional.
Add your own MiniMax key to bill usage to your MiniMax account instead of your ngrok.ai credits.
</Note>

## Setup

<Steps>
  <Step title="Create an access key and add credits">
    Follow the [quickstart](/ai-gateway/quickstart) to create an access key and purchase [credits](/ai-gateway/concepts/credits) in [app.ngrok.ai](https://app.ngrok.ai).
  </Step>

  <Step title="Store your MiniMax API key (optional)">
    Skip this step to pay with credits.
    To bring your own key, create an API key in your [MiniMax](https://www.minimax.io) account. Then [add a provider key](/ai-gateway/guides/attaching-provider-keys#add-a-provider-key) and [create an access key configuration](/ai-gateway/guides/access-key-configurations#create-a-configuration) with a `minimax` routing rule that uses it.
  </Step>

  <Step title="Send requests">
    Send requests with your access key:

    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://gateway.ngrok.ai/v1",
        api_key="ng-xxxxx-g1-xxxxx",
    )

    response = client.chat.completions.create(
        model="minimax:minimax-m3",
        messages=[{"role": "user", "content": "Hello!"}]
    )
    ```

    Tencent TokenHub also serves MiniMax M3, so the `minimax:` prefix keeps the request on MiniMax.
  </Step>
</Steps>

## Available models

See the [model catalog](/ai-gateway/reference/model-catalog#minimax).
Each `-highspeed` model is a separate model ID, not an option on the base model.
