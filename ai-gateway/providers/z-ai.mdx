[Z.ai](https://z.ai/model-api), formerly Zhipu AI, builds the open-weight GLM family of models for agents, reasoning, and coding.

Z.ai supports Chat Completions requests.

<Note>
Z.ai is a **built-in provider** you can pay for with credits, so a provider key is optional.
Add your own Z.ai key to bill usage to your Z.ai account instead of your ngrok.ai credits.
</Note>

## Setup

<Steps>
  <Step title="Create an access key and add credits">
    Follow the [quickstart](/ai-gateway/quickstart) to create an access key and purchase [credits](/ai-gateway/concepts/credits) in [app.ngrok.ai](https://app.ngrok.ai).
  </Step>

  <Step title="Store your Z.ai API key (optional)">
    Skip this step to pay with credits.
    To bring your own key, create an API key in your [Z.ai](https://z.ai/model-api) account. Then [add a provider key](/ai-gateway/guides/attaching-provider-keys#add-a-provider-key) and [create an access key configuration](/ai-gateway/guides/access-key-configurations#create-a-configuration) with a `z-ai` routing rule that uses it.
  </Step>

  <Step title="Send requests">
    Send requests with your access key:

    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://gateway.ngrok.ai/v1",
        api_key="ng-xxxxx-g1-xxxxx",
    )

    response = client.chat.completions.create(
        model="z-ai:glm-5.3",
        messages=[{"role": "user", "content": "Hello!"}]
    )
    ```

    QwenCloud, Tencent TokenHub, and Mistral AI also serve GLM models, so the `z-ai:` prefix keeps the request on Z.ai.
  </Step>
</Steps>
