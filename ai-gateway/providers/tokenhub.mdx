[Tencent TokenHub](https://www.tencentcloud.com/document/product/1300) serves models from several labs under one API key, including Tencent Hunyuan, Z.ai GLM, Moonshot AI Kimi, DeepSeek, MiniMax, Xiaomi MiMo, and StepFun.

Tencent TokenHub supports Chat Completions, Responses, and Anthropic Messages requests.

<Note>
Tencent TokenHub is a **built-in provider** you can pay for with credits, so a provider key is optional.
Add your own TokenHub key to bill usage to your Tencent Cloud account instead of your ngrok.ai credits.
</Note>

## Setup

<Steps>
  <Step title="Create an access key and add credits">
    Follow the [quickstart](/ai-gateway/quickstart) to create an access key and purchase [credits](/ai-gateway/concepts/credits) in [app.ngrok.ai](https://app.ngrok.ai).
  </Step>

  <Step title="Store your TokenHub API key (optional)">
    Skip this step to pay with credits.
    To bring your own key, create a TokenHub API key in your [Tencent Cloud](https://www.tencentcloud.com/document/product/1300) account. Then [add a provider key](/ai-gateway/guides/attaching-provider-keys#add-a-provider-key) and [create an access key configuration](/ai-gateway/guides/access-key-configurations#create-a-configuration) with a `tokenhub` routing rule that uses it.
  </Step>

  <Step title="Send requests">
    Send requests with your access key:

    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://gateway.ngrok.ai/v1",
        api_key="ng-xxxxx-g1-xxxxx",
    )

    response = client.chat.completions.create(
        model="tokenhub:tencent/hy3",
        messages=[{"role": "user", "content": "Hello!"}]
    )
    ```

    Many TokenHub models are also served by their own labs. Add the `tokenhub:` prefix, as in `tokenhub:moonshotai/kimi-k3`, to keep the request on TokenHub.
  </Step>
</Steps>
