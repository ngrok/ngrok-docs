title: Google
description: Use Google Gemini Chat Completions, GenerateContent, and Interactions through the ngrok AI Gateway.
---

[Google AI Studio](https://aistudio.google.com) provides Gemini models.
The gateway supports three APIs:

- OpenAI-compatible Chat Completions: if your OpenAI client already uses the gateway URL and your ngrok access key, change only the model name and send requests to `/v1/chat/completions`.
- Native Gemini GenerateContent: send requests to `/v1beta/models/{model}:generateContent` or `:streamGenerateContent` with a Gemini client.
- Native Gemini Interactions: send stateless create requests to `/v1beta/interactions`, with a JSON response or a stream of server-sent events (SSE).

The OpenAI Responses API (`/v1/responses`) doesn't reach Google models.

<Note>
Google is a **built-in provider** with ngrok.ai inference available, so a provider key is optional.
Add your own Google key to bill usage to your Google account instead of your ngrok credits.
</Note>

## Setup

<Steps>
  <Step title="Create an access key and add credits">
    Follow the [quickstart](/ai-gateway/quickstart) to create an access key and purchase [credits](/ai-gateway/concepts/credits) in [app.ngrok.ai](https://app.ngrok.ai).
  </Step>

  <Step title="Store your Google API key (optional)">
    Skip this step to use ngrok.ai inference.
    To bring your own key, generate one at [aistudio.google.com](https://aistudio.google.com), then [add a provider key](/ai-gateway/guides/attaching-provider-keys#add-a-provider-key).
  </Step>

  <Step title="Create a configuration">
    [Create an access key configuration](/ai-gateway/guides/access-key-configurations#create-a-configuration) with a `google` routing rule and allow Google in the access scope.
    To use your own Google key, set the routing rule to **Bring your own API key** and select your stored Google key.
  </Step>

  <Step title="Assign and send requests">
    Assign the configuration to your access key.
    Follow the [Google Gen AI SDK guide](/ai-gateway/sdks/google) to install the SDK and send requests.
  </Step>
</Steps>
