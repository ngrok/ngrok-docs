[DeepSeek](https://www.deepseek.com) provides high-performance reasoning and chat models.

DeepSeek supports Chat Completions, Responses, and Anthropic Messages requests.

<Note>
DeepSeek is a **built-in provider** you can pay for with credits, so a provider key is optional.
Add your own DeepSeek key to bill usage to your DeepSeek account instead of your ngrok credits.
</Note>

## Setup

<Steps>
  <Step title="Create an access key and add credits">
    Follow the [quickstart](/ai-gateway/quickstart) to create an access key and purchase [credits](/ai-gateway/concepts/credits) in [app.ngrok.ai](https://app.ngrok.ai).
  </Step>

  <Step title="Store your DeepSeek API key (optional)">
    Skip this step to pay with credits.
    To bring your own key, sign up at [platform.deepseek.com](https://platform.deepseek.com) and create an API key. Then [add a provider key](/ai-gateway/guides/attaching-provider-keys#add-a-provider-key) and [create an access key configuration](/ai-gateway/guides/access-key-configurations#create-a-configuration) with a `deepseek` routing rule that uses it.
  </Step>

  <Step title="Send requests">
    Send requests with your access key:

    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://gateway.ngrok.ai/v1",
        api_key="ng-xxxxx-g1-xxxxx",
    )

    response = client.chat.completions.create(
        model="deepseek-v4-flash",
        messages=[{"role": "user", "content": "Hello!"}]
    )
    ```
  </Step>
</Steps>
