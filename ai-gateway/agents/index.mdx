Coding agents that let you change their base URL can send their model requests through the AI Gateway.
Each agent then authenticates with an ngrok.ai [access key](/ai-gateway/concepts/access-keys) instead of a separate provider account, and every request shows up in one place.

Routing agents through the gateway gives you:

- One access key for every provider in the [model catalog](/ai-gateway/reference/model-catalog), billed to your credits or your own provider keys
- Per-request [observability](/ai-gateway/observability), with usage you can group by access key
- [Fallback models](/ai-gateway/guides/configure-fallback-models) and automatic retries when a provider fails
- Limits on which providers and models each key can call
- A path to [models you run yourself](/ai-gateway/guides/use-a-model-you-run-yourself), such as Ollama or vLLM

## How each agent connects

Each agent speaks one API format, which decides the base URL it needs:

| Agent | API format | Base URL |
|-------|------------|----------|
| Claude Code | Anthropic Messages | `https://gateway.ngrok.ai` |
| Codex | OpenAI Responses | `https://gateway.ngrok.ai/v1` |
| Cursor | OpenAI Chat Completions | `https://gateway.ngrok.ai/v1` |
| Hermes | OpenAI Chat Completions | `https://gateway.ngrok.ai/v1`, set by the plugin |
| OpenCode | OpenAI Chat Completions | `https://gateway.ngrok.ai/v1` |
| Pi | OpenAI Chat Completions | `https://gateway.ngrok.ai/v1` |
| Zed | OpenAI Chat Completions | `https://gateway.ngrok.ai/v1` |

The format also decides which models an agent can reach.
Chat Completions reaches the most providers.
The Messages and Responses formats only reach providers that support them, so Claude Code works with Claude models and Codex works best with OpenAI models.

## Set up for agent traffic

Coding agents send long, streaming requests, often many per task.
A few settings keep that traffic manageable:

- Create a separate access key for each agent or teammate, so you can [group usage by access key](/ai-gateway/observability) and revoke one without touching the others.
- Set `totalTimeout` to `15m` in [account settings](/ai-gateway/guides/account-settings#streaming-responses). A saved total timeout caps the whole stream, and saving any account setting stores the `2m` default, which can cut off a long agent response.
- Scope each key to the models it needs with an [access key configuration](/ai-gateway/guides/restrict-providers-and-models).
