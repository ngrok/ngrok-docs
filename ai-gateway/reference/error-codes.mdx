title: Error Codes Reference
description: When the AI Gateway encounters an error, it returns an ngrok error code and message to help identify the issue. The full list of AI Gateway error codes and their meanings are listed on this page.
---

These errors apply to requests sent to `https://gateway.ngrok.ai` with an [access key](/ai-gateway/concepts/access-keys).
Every response carries the request's ID in `Ngrok-AIG-Request-Id`, so quote that value when you contact support.
See [Response headers](/ai-gateway/how-it-works#response-headers).

## Request and routing errors

The gateway rejects these before it makes any upstream attempt, so the response carries no `Ngrok-AIG-Attempts` header and the request is not billed.

### ERR_NGROK_27228

**Message**

Invalid request: `REASON`

**HTTP Status**

400 Bad Request

**Causes**
- The request body is not valid JSON
- A required field is missing for the API surface you called
- A field holds a value the surface does not accept

**Solutions**
- Check the reason in the message for the offending field
- Verify the body matches the API surface you posted to, whether Chat Completions, Responses, Messages, or the native Gemini surface

---

### ERR_NGROK_27224

**Message**

Unknown model "`MODELID`".`SUGGESTION`

**HTTP Status**

400 Bad Request

**Causes**
- The model ID is misspelled
- The model is not in the [model catalog](/ai-gateway/reference/model-catalog) and no custom provider defines it

**Solutions**
- Check the suggestion in the message, which names the closest catalog match
- Look the model up in the [model catalog](/ai-gateway/reference/model-catalog)
- Qualify the model with its provider, such as `openai:gpt-4o`. See [Choose a model](/ai-gateway/guides/model-selection-strategies)

---

### ERR_NGROK_27225

**Message**

Unknown provider "`PROVIDERID`".

**HTTP Status**

400 Bad Request

**Causes**
- The provider prefix is misspelled
- The provider is a custom provider that does not exist on your account

**Solutions**
- List your providers with the [Providers API](/ai-gateway/api-reference/providers/list)
- [Register the custom provider](/ai-gateway/concepts/custom-providers) before routing to it

---

### ERR_NGROK_27230

**Message**

"`MODEL`" is not a known model, and "`PROVIDER`" is not a recognized provider.

**HTTP Status**

400 Bad Request

**Causes**
- A provider-qualified model name whose prefix is neither a known provider nor part of a real model ID

**Solutions**
- Use `provider:model`, with the provider exactly as the [Providers API](/ai-gateway/api-reference/providers/list) reports it
- Drop the prefix to let the gateway resolve the model from the catalog

---

### ERR_NGROK_27229

**Message**

Invalid model address "`ADDRESS`".

**HTTP Status**

400 Bad Request

**Causes**
- The model field is empty, or holds more separators than `provider:model` allows

**Solutions**
- Send either a bare model ID or a single `provider:model` pair

---

### ERR_NGROK_27204

**Message**

Unsupported API surface "`PATH`".

**HTTP Status**

400 Bad Request

**Causes**
- The request path is not one the gateway serves

**Solutions**
- Post to `/v1/chat/completions`, `/v1/responses`, `/v1/messages`, the native Gemini path `/v1beta/models/{model}:generateContent`, or `/v1beta/interactions`
- The gateway does not serve `/v1/embeddings`, `/v1/completions`, or image and audio endpoints
- Point your SDK's base URL at `https://gateway.ngrok.ai/v1` rather than a full endpoint path

---

### ERR_NGROK_27226

**Message**

Provider "`PROVIDERID`" does not support API surface "`SURFACE`".

**HTTP Status**

400 Bad Request

**Causes**
- The provider has no equivalent of the surface you called, such as the Responses API on a provider that only serves Chat Completions

**Solutions**
- Call the surface the provider supports. See the provider's page under [Getting Started With](/ai-gateway/providers/openai)
- Choose a different provider for that surface

---

### ERR_NGROK_27205

**Message**

API surface "`SURFACE`" is not implemented.

**HTTP Status**

501 Not Implemented

**Causes**
- The gateway knows this endpoint but doesn't support it yet

**Solutions**
- Use a supported endpoint such as `/v1/chat/completions`. See [ERR_NGROK_27204](#err_ngrok_27204) for the full list

---

### ERR_NGROK_27250

**Message**

ngrok doesn't store interactions yet, so "store" can't be true. Omit it or set it to false to send a stateless request.

**HTTP Status**

400 Bad Request

**Causes**
- An Interactions API request set `store` to `true`

**Solutions**
- Omit `store`, or set it to `false`. See [Google SDK](/ai-gateway/sdks/google)

---

## Access policy errors

### ERR_NGROK_27231

**Message**

Provider "`PROVIDERID`" is not allowed by the access policy.

**HTTP Status**

403 Forbidden

**Causes**
- The access key's configuration does not include the provider in its access scope

**Solutions**
- Allow the provider in the key's [access key configuration](/ai-gateway/guides/access-key-configurations)
- See [Restrict providers and models](/ai-gateway/guides/restrict-providers-and-models) for how scope is evaluated

---

### ERR_NGROK_27232

**Message**

Model "`MODELID`" is not allowed by the access policy.

**HTTP Status**

403 Forbidden

**Causes**
- The configuration's access scope excludes the model, even though the provider is allowed

**Solutions**
- Add the model to the access scope in the key's [access key configuration](/ai-gateway/guides/access-key-configurations)

---

## Credential and credit errors

### ERR_NGROK_27201

**Message**

Authentication failed: `REASON`

**HTTP Status**

401 Unauthorized

**Causes**
- No access key in the request
- The access key is malformed, revoked, or deleted

**Solutions**
- Send your [access key](/ai-gateway/concepts/access-keys) as `Authorization: Bearer ng-xxxxx-g1-xxxxx`, or as `x-api-key` on the Anthropic surface and `X-Goog-Api-Key` on the native Gemini surface
- Confirm the key still exists with the [Access Keys API](/ai-gateway/api-reference/access-keys/list)

---

### ERR_NGROK_27202

**Message**

No keys available for provider "`PROVIDERID`".

**HTTP Status**

502 Bad Gateway

**Causes**
- The access key's configuration has no routing credentials for the requested provider
- Every provider key the configuration referenced was deleted

**Solutions**
- Add a routing rule for the provider in the key's [access key configuration](/ai-gateway/guides/access-key-configurations)
- [Attach a provider key](/ai-gateway/guides/attaching-provider-keys#add-a-provider-key), or [pay with credits](/ai-gateway/guides/pay-with-credits) where the provider supports it

---

### ERR_NGROK_27206

**Message**

Credit check failed: `REASON`

**HTTP Status**

402 Payment Required

**Causes**
- The account's credit balance is zero or below, or billing is not set up for the account yet
- Every request needs credits, even with your own provider keys, because each one pays a small processing fee

**Solutions**
- Check your balance with the [Credits API](/ai-gateway/api-reference/credits/balance)
- [Purchase credits](https://app.ngrok.ai/billing). Your own provider key does not bypass this check

---

### ERR_NGROK_27233

**Message**

Model "`MODELID`" is not available with an ngrok-managed key for provider "`PROVIDERID`": add your own provider key to use uncataloged models.

**HTTP Status**

400 Bad Request

**Causes**
- The model is not in ngrok's catalog, so ngrok has no pricing to bill it against

**Solutions**
- [Attach your own provider key](/ai-gateway/guides/attaching-provider-keys) for that provider
- Pick a catalog model instead. See the [model catalog](/ai-gateway/reference/model-catalog)

---

### ERR_NGROK_27239

**Message**

ngrok can't serve "`MODELID`" on provider "`PROVIDERID`" with an ngrok-managed key right now. Add your own provider key to use it.

**HTTP Status**

503 Service Unavailable

**Causes**
- You can't pay for this model with credits on that provider right now

**Solutions**
- Retry, or fail over to another model. See [Configure fallback models](/ai-gateway/guides/configure-fallback-models)
- [Attach your own provider key](/ai-gateway/guides/attaching-provider-keys) for that provider

---

### ERR_NGROK_27236

**Message**

Model "`MODELID`" is not priced for managed billing yet for provider "`PROVIDERID`"; add your own provider key to use it.

**HTTP Status**

400 Bad Request

**Causes**
- You can't pay for this model with credits on that provider yet, because ngrok doesn't have a price for it

**Solutions**
- [Attach your own provider key](/ai-gateway/guides/attaching-provider-keys) for that provider
- Pick another model from the [model catalog](/ai-gateway/reference/model-catalog)

---

### ERR_NGROK_27238

**Message**

An ngrok-managed key can't serve this request, because ngrok can't bill `FEATURE` for "`MODELID`" on provider "`PROVIDERID`". Add your own provider key to use it.

**HTTP Status**

400 Bad Request

**Causes**
- The request uses a feature, such as a hosted tool, that you can't pay for with credits on that model

**Solutions**
- Remove the feature from the request
- [Attach your own provider key](/ai-gateway/guides/attaching-provider-keys) for that provider

---

### ERR_NGROK_27249

**Message**

ngrok doesn't offer "`MODELID`" on provider "`PROVIDERID`" with an ngrok-managed key. Add your own provider key to use it.

**HTTP Status**

400 Bad Request

**Causes**
- The model exists in the catalog, but you can't pay for it with credits on that provider

**Solutions**
- [Attach your own provider key](/ai-gateway/guides/attaching-provider-keys) for that provider
- Pick a model you can pay for with credits. See the [model catalog](/ai-gateway/reference/model-catalog#billing-and-provider-credentials)

---

### ERR_NGROK_27240

**Message**

Your account has no `FILES` for provider "`PROVIDERID`". An ngrok-managed key can only use files your account uploaded. Upload the file first, or add your own provider key.

**HTTP Status**

404 Not Found

**Causes**
- The request uses a file that wasn't uploaded from your account, so you can't pay for it with credits

**Solutions**
- [Attach your own provider key](/ai-gateway/guides/attaching-provider-keys) to use files stored in your provider account

---

## Upstream failures

These arrive after the gateway tries at least one provider, so `Ngrok-AIG-Attempts` tells you how many tries the gateway made.
See [Handle gateway errors](/ai-gateway/guides/error-handling) for the order it tries them in.
When every model fails, or the request hits the 10-attempt cap, the gateway returns the last model's error.

### ERR_NGROK_27211

**Message**

Upstream provider rejected the API key.

**HTTP Status**

401 Unauthorized

**Causes**
- The provider key stored in ngrok is invalid, revoked, or rotated at the provider

**Solutions**
- [Rotate the provider key](/ai-gateway/api-reference/provider-keys/rotate) to the current value
- Verify the key directly against the provider

---

### ERR_NGROK_27217

**Message**

Upstream provider rate limit exceeded.

**HTTP Status**

429 Too Many Requests

**Causes**
- Every credential and candidate the gateway tried was rate limited

**Solutions**
- Attach more [provider keys](/ai-gateway/guides/attaching-provider-keys) so the gateway has another credential to try
- Add candidates from other providers. See [Multi-provider failover](/ai-gateway/examples/multi-provider-failover)
- Slow your request rate, or raise your quota with the provider

---

### ERR_NGROK_27207

**Message**

Upstream request timed out.

**HTTP Status**

504 Gateway Timeout

**Causes**
- A single upstream attempt exceeded the per-request timeout

**Solutions**
- Raise the per-request timeout in [Account Settings](/ai-gateway/guides/account-settings)
- Shorten the prompt, or choose a faster model

---

### ERR_NGROK_3810

**Message**

Request timed out after `TIMEOUT`. Try a shorter prompt or increase your timeout.

**HTTP Status**

504 Gateway Timeout

**Causes**
- Every attempt together exceeded the total timeout
- Too many slow candidates in the failover list

**Solutions**
- Raise the total timeout in [Account Settings](/ai-gateway/guides/account-settings)
- Lower the per-request timeout so a slow provider fails sooner and leaves budget for the next candidate
- Reduce the number of failover candidates

---

### ERR_NGROK_27227

**Message**

No backend available: `REASON`

**HTTP Status**

502 Bad Gateway

**Causes**
- No candidate remained that the gateway could dispatch to

**Solutions**
- Confirm the configuration's routing rules cover the provider you requested
- See [Handle gateway errors](/ai-gateway/guides/error-handling) for how candidates are exhausted

---

### ERR_NGROK_27237

**Message**

Request rejected: a routing loop was detected. Double check your custom provider URLs do not cause an infinite proxy loop.

**HTTP Status**

502 Bad Gateway

**Causes**
- A custom provider's base URL points back at the AI Gateway

**Solutions**
- Point the custom provider at its real upstream. See [Use a model you run yourself](/ai-gateway/guides/use-a-model-you-run-yourself)

---

## Limit errors

### ERR_NGROK_3811

**Message**

Input too large: `INPUTTOKENS` tokens (max `MAXALLOWED`). Shorten your prompt.

**HTTP Status**

413 Payload Too Large

**Causes**
- The prompt and context exceed the account's max input tokens
- Very long conversation history, or large embedded content in messages

**Solutions**
- Reduce the prompt length or conversation history
- Raise or clear `maxInputTokens` in [Account Settings](/ai-gateway/guides/account-settings)
- Count tokens client-side before sending

---

### ERR_NGROK_AI_GATEWAY_REQUEST_BODY_TOO_LONG

**Message**

Request body is too long. Max 32 MiB.

**HTTP Status**

413 Payload Too Large

**Causes**
- The request body is larger than 32 MiB

**Solutions**
- Send large inputs, such as documents and images, through the provider's files API instead of inline
- Reduce the conversation history or embedded content

---

## Retired setup

### ERR_NGROK_3820

**Message**

```text
AI Gateway has a new home at https://app.ngrok.ai. The old ai-gateway traffic
policy action has been retired. Existing credits have been migrated to
https://app.ngrok.ai. If you have any questions or issues, please reach out to
support@ngrok.com.
```

**HTTP Status**

403 Forbidden

**Causes**
- A Traffic Policy still contains the retired `ai-gateway` action

**Solutions**
- Remove the `ai-gateway` action from the endpoint's Traffic Policy
- Send LLM traffic to `https://gateway.ngrok.ai` with an [access key](/ai-gateway/concepts/access-keys) instead, and manage the gateway at [app.ngrok.ai](https://app.ngrok.ai)
- Credits from the retired setup were migrated automatically. Email [support@ngrok.com](mailto:support@ngrok.com) if your balance looks wrong

---

## Other codes

The gateway returns one code per upstream status class, beyond the ones above.
Each has a page under [ngrok error codes](/errors):

| Code | Meaning |
|------|---------|
| `ERR_NGROK_27210` | Upstream provider rejected the request |
| `ERR_NGROK_27212` | Upstream provider denied access |
| `ERR_NGROK_27213` | Upstream provider returned not found |
| `ERR_NGROK_27214` | Upstream provider request timed out |
| `ERR_NGROK_27215` | Request payload exceeded upstream provider limits |
| `ERR_NGROK_27216` | Upstream provider could not process the request |
| `ERR_NGROK_27218` | Upstream provider returned an internal server error |
| `ERR_NGROK_27219` | Upstream provider returned a bad gateway error |
| `ERR_NGROK_27220` | Upstream provider is unavailable |
| `ERR_NGROK_27221` | Upstream provider gateway timed out |
| `ERR_NGROK_27222` | Upstream provider returned an unexpected status |
| `ERR_NGROK_27234` | Upstream returned a non-streaming response to a streaming request |
| `ERR_NGROK_27235` | Upstream provider failed to respond, for example a dropped connection |
| `ERR_NGROK_27241` to `ERR_NGROK_27248` | Files API errors |

## SDK error handling

Handle ngrok errors in your SDK:

<CodeGroup>
```python OpenAI Python SDK
from openai import OpenAI, APIError

client = OpenAI(
    base_url="https://gateway.ngrok.ai/v1",
    api_key="ng-xxxxx-g1-xxxxx"
)

try:
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": "Hello"}]
    )
except APIError as e:
    print(f"Error code: {e.code}")
    print(f"Message: {e.message}")
    if "ERR_NGROK_27224" in str(e):
        print("Model not found - check model name spelling")
```

```javascript OpenAI Node.js SDK
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://gateway.ngrok.ai/v1',
  apiKey: 'ng-xxxxx-g1-xxxxx',
});

try {
  const response = await client.chat.completions.create({
    model: 'gpt-4o',
    messages: [{ role: 'user', content: 'Hello' }],
  });
} catch (error) {
  if (error instanceof OpenAI.APIError) {
    console.log('Status:', error.status);
    console.log('Message:', error.message);
    if (error.message.includes('ERR_NGROK_27224')) {
      console.log('Model not found - check model name spelling');
    }
  }
}
```
</CodeGroup>
