<Update label="2026-10-15" description="Automatic top-up" tags={["General Availability"]}>
  ## Never run out of credits

  Turn on automatic top-up and ngrok refills your balance from your saved card whenever it runs low. You choose when it tops up and how much, and you can cap how much it spends each billing period.
  See [Automatic top-up](/ai-gateway/concepts/credits#automatic-top-up).
</Update>

<Update label="2026-10-14" description="Card approvals and a request size limit" tags={["General Availability"]}>
  ## Approve card payments that need an extra check

  Some banks ask you to confirm a payment before it goes through. When that happens while you buy credits, you now get a link to approve the payment, and your credits arrive once you do.
  See [Credits](/ai-gateway/concepts/credits#purchasing-credits).

  ## Requests can be up to 32 MiB

  Requests larger than 32 MiB are now turned away with a clear error, before they reach a provider.
  Most requests are far below this. If you hit it, trim long conversation history or large embedded documents.
</Update>

<Update label="2026-10-07" description="See what was left out of your request" tags={["General Availability"]}>
  ## Know when a setting didn't reach the model

  Not every model supports every setting. When the gateway has to leave a setting out because the model can't use it, the response now tells you which ones.
  See [Response headers](/ai-gateway/how-it-works#response-headers).
</Update>

<Update label="2026-10-04" description="Longer streaming responses" tags={["General Availability"]}>
  ## Long answers no longer get cut off

  Streaming responses can now keep going for up to 15 minutes, which helps with long answers and slow reasoning models.
  If you've set your own total timeout, it still applies.
  See [Streaming responses](/ai-gateway/guides/account-settings#streaming-responses).
</Update>

<Update label="2026-09-24" description="Pay with credits for more providers" tags={["General Availability"]}>
  ## Use more providers without signing up for them

  You can now pay with credits for models from Google, DeepSeek, xAI, Moonshot AI, Z.ai, Qwen Cloud, MiniMax, and more, in addition to OpenAI and Anthropic.
  You don't need an account or API key with those providers.
  The [model catalog](/ai-gateway/reference/model-catalog#billing-and-provider-credentials) shows which models work this way.
</Update>

<Update label="2026-09-04" description="Easier request troubleshooting" tags={["General Availability"]}>
  ## See why a fallback model didn't run

  If a model you listed as a fallback couldn't be used, for example because your access key isn't allowed to call it, the response now names it.
  See [Response headers](/ai-gateway/how-it-works#response-headers).

  ## Follow every retry for a request

  You can now look up a single request and see each attempt the gateway made, what happened, and why it moved on.
  See [Why a request failed over](/ai-gateway/guides/why-a-request-failed-over).
</Update>

<Update label="2026-09-02" description="Response headers" tags={["General Availability"]}>
  ## Request ID, attempt count, and served model on every response

  Gateway responses now state how the request was handled:

  - `Ngrok-AIG-Request-Id`: the request's ID, on every response including rejections and errors.
  - `Ngrok-AIG-Attempts`: how many upstream attempts the gateway made.
  - `Ngrok-AIG-Model`: the upstream model that produced the response.

  All three are exposed through CORS, so browser clients can read them.
  They are ngrok's own headers, so managed-key and Bring Your Own Keys callers see the same values.
  See [Response headers](/ai-gateway/how-it-works#response-headers).

  The native Gemini `generateContent` and `streamGenerateContent` surface returns these headers too, where it previously returned only `Content-Type`.
  Bodies on that surface are still forwarded byte-for-byte.
</Update>

<Update label="2026-08-20" description="Traffic Policy action retired" tags={["Breaking Change"]}>
  ## The ai-gateway Traffic Policy action is retired

  The AI Gateway no longer runs as a Traffic Policy action on your own endpoint.
  A policy that still contains the `ai-gateway` action fails validation with `ERR_NGROK_3820`.

  - Send LLM traffic to `https://gateway.ngrok.ai` with an [access key](/ai-gateway/concepts/access-keys), and manage the gateway at [app.ngrok.ai](https://app.ngrok.ai).
  - Existing credits were migrated to [app.ngrok.ai](https://app.ngrok.ai) automatically. No action is needed to keep your balance.
  - Remove the `ai-gateway` action from any endpoint that still carries it.
  - The action's result variables, such as `actions.ngrok.ai_gateway`, are gone. Read the [response headers](/ai-gateway/how-it-works#response-headers) and the [Usage API](/ai-gateway/api-reference/usage/list) instead.

  Email [support@ngrok.com](mailto:support@ngrok.com) with questions about a migrated account.
</Update>

<Update label="2026-06-23" description="app.ngrok.ai launch" tags={["General Availability"]}>
  ## app.ngrok.ai and gateway.ngrok.ai

  Manage your AI Gateway from [app.ngrok.ai](https://app.ngrok.ai) and send traffic to a shared gateway URL:

  - Manage [access keys](/ai-gateway/concepts/access-keys), [access key configurations](/ai-gateway/guides/access-key-configurations), provider keys, credits, and settings at **[app.ngrok.ai](https://app.ngrok.ai)**.
  - Send LLM traffic from your applications to **`https://gateway.ngrok.ai`** with an access key only—provider keys are stored server-side.
  - Updated the [Quickstart](/ai-gateway/quickstart), [Overview](/ai-gateway/overview), [How It Works](/ai-gateway/how-it-works), and [Access Keys](/ai-gateway/concepts/access-keys).
  - [Provider keys](/ai-gateway/guides/attaching-provider-keys) are now account-scoped in app.ngrok.ai BYOK.
  - Endpoint-based Traffic Policy setup is deprecated.
</Update>

<Update label="2026-02-24" description="EA v0.0.5" tags={["Early Access"]}>
  ## AI Gateway API keys & credits

  You can now authenticate requests to your AI Gateway with **AI Gateway API Keys**—no provider accounts needed. The AI Gateway manages the provider keys for OpenAI and Anthropic on your behalf. Purchase prepaid credits to fund usage.

  - [AI Gateway API Keys](/ai-gateway/concepts/access-keys): Create keys to authenticate requests
  - [Credits](/ai-gateway/concepts/credits): Understand pricing and balance management
  - [Bring Your Own Keys](/ai-gateway/concepts/bring-your-own-keys): Use your own provider keys for additional providers
  - Updated [Quickstart](/ai-gateway/quickstart), [Overview](/ai-gateway/overview), and all [SDK guides](/ai-gateway/sdks) to use AI Gateway API Keys as the primary path
</Update>
