The ngrok.ai API lets you manage ngrok.ai directly from your code, so you don't have to rely on the dashboard.

You can use it to create access keys, add provider keys, set up routing and access rules, register custom providers, check usage, and keep an eye on your credit balance.

The API doesn't handle model requests itself.
To call models, send your requests to `https://gateway.ngrok.ai` using an access key.

## Base URL

When you make requests to the ngrok.ai API, send them to:

```text
https://api.ngrok.ai
```

The ngrok.ai API uses JSON for both requests and responses, and you must make all calls over HTTPS.

## Authentication

To authenticate, include your [ngrok.ai API key](/ai-gateway/concepts/access-keys#credentials-overview) in the `Authorization` header of each request:

```bash
curl https://api.ngrok.ai/access-keys \
  -H "Authorization: Bearer $AI_GATEWAY_API_KEY"
```

You can create and manage your ngrok.ai API key on the settings page in the dashboard.
Treat this key like a secret, since it allows you to manage the resources in your account.

## Scopes

Each route needs a scope.
An API key can call a route only when it has that scope.
The two key types accept different scopes when you create them:

- **Access keys** accept `ai-gateway:inference:request` for inference requests.
- **API keys** accept one or more AI Gateway management scopes, such as `ai-gateway:access-keys:read`, which lets the key list and view access keys and access key configurations.
  Read-only management scopes count.

Most resources have a `read` scope, to view them, and a `write` scope, to create, change, and delete them.

| Resource | Scopes | What it covers |
|---|---|---|
| Access keys | `ai-gateway:access-keys:read`, `ai-gateway:access-keys:write` | Access keys and access key configurations. |
| API keys | `ai-gateway:api-keys:read`, `ai-gateway:api-keys:write` | ngrok.ai API keys. |
| Credits | `ai-gateway:credits:read`, `ai-gateway:credits:write` | The credit balance, transactions, and purchases. |
| Providers | `ai-gateway:providers:read`, `ai-gateway:providers:write` | Providers, provider keys, and the model list. |
| Settings | `ai-gateway:settings:read`, `ai-gateway:settings:write` | Gateway configuration and firewall policies. |
| Usage | `ai-gateway:usage:read` | Usage data and request logs. |
| Virtual models | `ai-gateway:virtual-models:read`, `ai-gateway:virtual-models:write` | Virtual models. |

Access keys use `ai-gateway:inference:request` for model requests to `https://gateway.ngrok.ai`.
This scope doesn't grant access to the management API.

### Missing scopes

When an API key calls a route without the scope it needs, the API returns `403 Forbidden` and names the missing scope:

```text
You don't have permission to perform this action. Your credentials are missing the 'ai-gateway:access-keys:write' scope.
```

To fix the error, add the scope to the API key.

## OpenAPI spec

A public OpenAPI 3.0 spec describes the API.
Use it to generate a client in any language, or load it into your API tooling:

```text
https://api.ngrok.ai/openapi.yaml
```

## What you can manage

Use the AI Gateway API to manage:

* [Access keys](/ai-gateway/api-reference/access-keys/list): Manage keys for making gateway requests
* [Access key configurations](/ai-gateway/api-reference/access-key-configurations/list): Manage access controls and rules for which providers, models, and keys an access key can use
* [Providers](/ai-gateway/api-reference/providers/list): Manage which providers the gateway can route to
* [Provider keys](/ai-gateway/api-reference/provider-keys/list): Manage your credentials for providers 
* [API keys](/ai-gateway/api-reference/api-keys/list): Manage keys that grant ngrok.ai API access
* [Configuration](/ai-gateway/api-reference/gateway-config/get): Manage your account level gateway settings
* [Credits](/ai-gateway/api-reference/credits/balance): View your credit balance and transactions, and start a purchase
* [Models](/ai-gateway/api-reference/models/list): List every model your account can reach, with pricing and provider metrics
* [Virtual models](/ai-gateway/api-reference/virtual-models/list): Manage names that stand for an ordered list of models to try in turn
* [Usage](/ai-gateway/api-reference/usage/list): View data on requests, tokens, providers, models, and costs

## Common workflows

Use the ngrok.ai API to automate common setup and operational tasks.

### Create access keys

Create access keys for applications, environments, teams, or customers.
Each access key can have its own configuration for routing, model access, and provider credentials.

### Add provider keys

Store upstream provider credentials so ngrok.ai can call providers on your behalf without exposing those credentials in your application code.

### Configure routing and access

Define access key configurations to control which providers and models an access key can call, and which provider keys are used for upstream authentication.

### Register custom providers

Create custom providers for self-hosted models, private deployments, or other OpenAI-compatible and Anthropic-compatible APIs.

### Monitor usage and credits

Query usage and credit data to track requests, tokens, costs, and remaining balance.
