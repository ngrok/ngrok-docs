Send these prompts to an AI agent that's connected to the [ngrok MCP server](/mcp-server).
The AI agent answers from your own account, so every answer is about your endpoints, traffic, and team.

Prompts that change your account, such as saving a Traffic Policy, ask you to approve the change first.
See [Make changes safely](/mcp-server#make-changes-safely).

## Try it now

Name a service in the second prompt to choose which one the AI agent looks at.
In the third, ask for any response a [`custom-response`](/gateway/traffic-policy/actions/custom-response) action can send, such as JSON or an HTML page.
To keep changing that page, see [Build a page, then change it](#build-a-page-then-change-it).

<PromptList prompts={[
	"What new tricks did ngrok just teach you?",
	"Tell me about the traffic hitting one of my services.",
	"Put a page online that greets each visitor with their IP address and country. Don't run anything on my machine.",
]} />

## Understand what's running

These prompts cover what's connected right now, plus your reserved domains and certificates.
Swap in the [error code](/errors) you got.
If the ngrok error page also shows a request ID, paste both.

<PromptList prompts={[
	"What's online right now?",
	"Is ngrok still running somewhere I forgot about?",
	"Which agent version is each device running?",
	"Which of my TLS certificates expire this month?",
	"Why does my custom domain show TLS errors?",
	"I got ERR_NGROK_8012 when I opened my ngrok URL. What's wrong, and how do I fix it?",
]} />

## Analyze traffic

These prompts read [Traffic Inspector](/obs/traffic-inspection), including [TCP connections](/obs/traffic-inspection/tcp-connections).
How far back your AI agent can look depends on your plan's retention.
Narrow any prompt to a host, path, status code, method, or client IP, and ask for counts by hour, by day, or by country.

<PromptList prompts={[
	"Which of my URLs got the most HTTP traffic?",
	"Are any of my endpoints on fire? Show me 500s by hour for the last day.",
	"Which of my endpoints are throwing 502s or 503s, and why?",
	"Which countries send me the most traffic?",
	"Who connects to my TCP endpoint, and how long do they stay?",
]} />

## Create traffic rules

The AI agent writes [Traffic Policy](/gateway/traffic-policy), checks it with the validator, and saves it to a Cloud Endpoint.
The MCP server can't write to your ngrok agent's config file, but a coding agent can edit that file itself.
Swap in your own paths, limits, and countries, or another [OAuth provider](/gateway/traffic-policy/actions/oauth), such as GitHub or Microsoft.
See [Traffic Policy actions](/gateway/traffic-policy/actions) for everything a rule can do.

<PromptList prompts={[
	"Write a rule that rate-limits my busiest path to 100 requests a minute.",
	"Write the ngrok config to put this project online behind a Google login that only lets me in, and check that it's valid.",
	"Only let traffic from the US and Canada reach my API.",
	"Add the visitor's country as a header on every request.",
	"Put up a maintenance page on my API.",
	"Redirect www to my apex domain.",
	"Block the top IP hitting /login.",
]} />

## Set up endpoints and resources

The AI agent can create and change Cloud Endpoints, reserved domains, TCP addresses, vaults, and secrets.
Swap in your own domain, and name the service or vault you mean.
It asks before it deletes anything, and it can confirm that a secret exists but can't read it back.

<PromptList prompts={[
	"Set up api.example.com as a Cloud Endpoint that forwards to my internal service.",
	"Store my Stripe webhook secret in a vault and verify webhooks with it.",
	"Release the TCP addresses that no endpoint uses.",
]} />

## Check your account

Change the time window, or ask about authtokens, SSH keys, or personal access tokens instead of API keys.
The AI agent sees each credential's description, owner, and dates, but never the key or token itself.

<PromptList prompts={[
	"How much of my plan have I used this month?",
	"Am I close to hitting any limits?",
	"Am I being rate limited? Why are my requests failing?",
	"Which endpoints used the most data this month?",
	"Who's on my team, and which API keys does each person own?",
	"Which of my API keys are more than a year old, and who owns them?",
	"Revoke the authtoken on my old laptop.",
]} />

## Send feedback

The AI agent sends feedback about the MCP server's tools to the ngrok team.
In the second prompt, replace `<YOUR_IDEA_HERE>` with your idea.

<PromptList prompts={[
	"You couldn't answer my last question. Tell the ngrok team what was missing.",
	"Tell the ngrok team I want <YOUR_IDEA_HERE>.",
]} />

## Chain prompts

Send the prompts in a chain one after another in the same session.
Each prompt builds on the answer before it.

### Build a page, then change it

<PromptList prompts={[
	"Put a page online that greets each visitor with their IP address and country. Don't run anything on my machine.",
	"Now greet them in their own language.",
	"Put that page behind a Google login.",
]} />

### Find bad traffic, then block it

Swap the login page for any path you want to protect, and change the second prompt to match.

<PromptList prompts={[
	"Who's hammering my login page, and from where?",
	"Block that stuff before it ever reaches the login.",
	"Check that it works.",
]} />
