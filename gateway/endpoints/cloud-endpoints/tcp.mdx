This page covers what is specific to TCP Cloud Endpoints.
For TCP URL formats, authentication, observability, limits, and errors shared with Agent Endpoints, see the [TCP Agent Endpoint reference](/gateway/endpoints/tcp).

## Create a TCP Cloud Endpoint

Follow the [Cloud Endpoints Quickstart](/getting-started/cloud-endpoints-quickstart) for the dashboard and API workflow.
For a public TCP endpoint, first reserve a [TCP Address](/gateway/domains/tcp-addresses/), then create the Cloud Endpoint with that address and a Traffic Policy:

```bash title="Command line"
ngrok api endpoints create \
  --url tcp://{your-tcp-address}.ngrok.io:{your-port} \
  --traffic-policy "$(<traffic-policy.yml)"
```

## Traffic Policy

Every Cloud Endpoint requires a [Traffic Policy](/gateway/traffic-policy/) to handle incoming traffic.
For TCP endpoints, available authentication actions include [IP Restriction](/gateway/traffic-policy/actions/restrict-ips/) and [Mutual TLS](/gateway/traffic-policy/actions/terminate-tls/).
