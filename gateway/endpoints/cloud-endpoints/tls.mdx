This page covers what is specific to TLS Cloud Endpoints.
For TLS behavior, client compatibility, limits, observability, and examples shared with Agent Endpoints, see the [TLS Agent Endpoint reference](/gateway/endpoints/tls).

## Create a TLS Cloud Endpoint

Follow the [Cloud Endpoints Quickstart](/getting-started/cloud-endpoints-quickstart) to create an endpoint in the dashboard or API.
Use a `tls://` URL and attach a Traffic Policy.

For example, create one with the API and a reserved domain:

```bash
ngrok api endpoints create \
  --url tls://{your-domain-here}.ngrok.app \
  --traffic-policy "$(<traffic-policy.yml)"
```

## URLs

See [TLS Agent Endpoint URLs](/gateway/endpoints/tls#urls) for the URL format and [Public Endpoint URLs](/gateway/endpoints/public-endpoints/#https-tls) for domain requirements.

## Bindings

TLS Cloud Endpoints support `public` and `internal` bindings, but not the `kubernetes` binding.

## Traffic Policy

Every Cloud Endpoint requires a [Traffic Policy](/gateway/traffic-policy/) to handle incoming traffic.
For public TLS endpoints, the available authentication actions are [IP Restriction](/gateway/traffic-policy/actions/restrict-ips/) and [Mutual TLS](/gateway/traffic-policy/actions/terminate-tls/).

## TLS Termination

The ngrok cloud service can terminate TLS before applying the Cloud Endpoint's Traffic Policy.
To keep traffic encrypted from the ngrok network to your service, forward it to an internal Agent Endpoint that terminates TLS at the agent or upstream.

See [TLS termination locations](/gateway/domains/tls-termination/#termination-location) for the available termination points and [end-to-end encryption](/gateway/domains/tls-termination/#end-to-end-encryption) for the setup requirements.

Zero-knowledge TLS is available on the Pay-as-you-go plan.

## Certificates

When ngrok terminates TLS, it selects and manages the certificate for the endpoint's domain.
For certificate selection and management, see [TLS certificates](/gateway/domains/tls-certificates/).
For custom and wildcard domain pricing, see [Domains pricing](/gateway/domains/#pricing).
