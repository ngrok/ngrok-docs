## KubernetesOperator custom resource

### **apiVersion:** `ngrok.com/v1`

### **kind:** `KubernetesOperator`

<Warning title="ngrok.k8s.ngrok.com/v1alpha1 KubernetesOperator is deprecated">
The Operator now manages an `ngrok.com/v1` `KubernetesOperator` for you; no action is needed.
Upgrade through both 0.25 and 1.0.
Use `kubernetesoperators.ngrok.com` in kubectl commands.
See the [0.25 upgrade guide](https://github.com/ngrok/ngrok-operator/blob/main/docs/upgrading-to-0.25.md).
</Warning>

The `KubernetesOperator` custom resource handles synchronizing the state of your ngrok Kubernetes Operator instance with the ngrok API.
A `KubernetesOperator` resource is created automatically when you install the ngrok Operator with Helm and has configuration that matches your installation options from Helm so that you can identify it in the ngrok cloud.

## KubernetesOperator structure and types

The following outlines the high level structure and typings of a `KubernetesOperator`:

```yaml
apiVersion: ngrok.com/v1
kind: KubernetesOperator
metadata:
  name: <string>
  namespace: <string>
spec:
  description: <string>           # optional, default: "Created by ngrok-operator"
  metadata: <map[string]string>   # optional, default: {"owned-by": "ngrok-operator"}
  enabledFeatures: <[]string>     # optional
  region: <string>                # optional, default: "global"
  deployment:                     # optional
    name: <string>                # optional
    namespace: <string>           # optional
    version: <string>             # optional
  binding:                        # optional
    endpointSelectors: <[]string> # required
    ingressEndpoint: <string>     # optional
    tlsSecretName: <string>       # required, default: "default-tls"
  drain:                          # optional
    policy: <string>              # optional, default: "Retain"
```

### `spec.drain`

Configuration of the drain behavior during operator uninstall.
For more information, see [Uninstalling the Operator](/gateway/k8s/installation/uninstall).

**Type:** `Object`

**Required:** no

**Default:** none

**Fields:**

| Field Name                                | Type            | Required | Default    | Description                                                             |
| ----------------------------------------- | --------------- | -------- | ---------- | ----------------------------------------------------------------------- |
| [`spec.drain.policy`](#specdrainpolicy)   | `string` (enum) | no       | `"Retain"` | Determines whether to delete ngrok API resources or just remove finalizers during drain |

### `spec.drain.policy`

Determines how ngrok API resources are handled when the operator is uninstalled.

**Type:** `string (enum)`

**Required:** no

**Default:** `"Retain"`

**Allowed Values:** `"Delete"`, `"Retain"`

- `Retain`: removes finalizers from custom resources but preserves ngrok API resources in your account
- `Delete`: deletes each custom resource and waits for the operator to clean up the corresponding ngrok API resource

## Status fields

The `KubernetesOperator` resource includes status information that reflects the current state of the operator and its registration with the ngrok API.

### `status.observedGeneration`

The most recent `metadata.generation` the Operator observed.
When it matches `metadata.generation`, the status reflects the latest spec.

**Type:** `int64`

### `status.id`

The unique identifier for this Kubernetes Operator in the ngrok API.

**Type:** `string`

### `status.uri`

The URI for this Kubernetes Operator in the ngrok API.

**Type:** `string`

### `status.enabledFeatures`

The features enabled for this Kubernetes Operator, as reported by the ngrok API.

**Type:** `[]string`

### `status.bindingsIngressEndpoint`

The URL that the operator uses to talk to the ngrok network when forwarding traffic for kubernetes-bound endpoints.

**Type:** `string`

### `status.drain`

Reports the progress of the drain that deleting this resource triggers.
For more information, see [Uninstalling the Operator](/gateway/k8s/installation/uninstall).

**Type:** `Object`

**Fields:**
- `drainedResources` - The number of resources successfully drained in the latest attempt
- `failedResources` - The number of resources that could not be drained in the latest attempt
- `totalResources` - The total number of resources the drain processes
- `errors` - The most recent errors encountered during drain (up to 20)

### `status.conditions`

Standard Kubernetes conditions that indicate the state of the Kubernetes Operator.

**Type:** `[]Condition`

#### Condition types

##### `Ready`

Summarizes the overall health of the `KubernetesOperator`.

**Reasons:**

| Reason | Status | Meaning |
|--------|--------|---------|
| `Registered` | `True` | The operator is registered with the ngrok API and ready |
| `Pending` | `False` | Waiting to be registered with the ngrok API |
| `RegistrationFailed` | `False` | Registration with the ngrok API failed |
| `ConfigurationFailed` | `False` | The operator is registered, but its configuration, such as bindings, failed |
| `Draining` | `False` | The resource is being deleted and the drain has started |
| `DrainFailed` | `False` | The drain encountered errors and is retrying |
| `DrainCompleted` | `False` | The drain finished |

##### `Registered`

Reports whether this operator is registered with the ngrok API.

**Reasons:**

| Reason | Status | Meaning |
|--------|--------|---------|
| `Registered` | `True` | Registered with the ngrok API |
| `Pending` | `False` | Waiting to be registered with the ngrok API |
| `RegistrationFailed` | `False` | Registration with the ngrok API failed |
| `Deregistered` | `False` | Deregistered from the ngrok API during deletion |

##### `Draining`

Present only while the resource is being deleted.

**Reasons:**

| Reason | Status | Meaning |
|--------|--------|---------|
| `DrainInProgress` | `True` | The drain of managed resources is in progress |
| `DrainFailed` | `True` | The drain encountered errors and is retrying |
| `DrainCompleted` | `False` | The drain finished |

## Status examples

### Registered Operator

```yaml
status:
  id: k8sop_2example123
  uri: /kubernetes_operators/k8sop_2example123
  enabledFeatures:
  - ingress
  - gateway
  - bindings
  conditions:
  - type: Registered
    status: "True"
    reason: Registered
    message: "Registered with the ngrok API"
    lastTransitionTime: "2025-10-29T00:39:15Z"
    observedGeneration: 1
  - type: Ready
    status: "True"
    reason: Registered
    message: "KubernetesOperator is registered and ready"
    lastTransitionTime: "2025-10-29T00:39:15Z"
    observedGeneration: 1
```

### Operator draining during uninstall

```yaml
status:
  id: k8sop_2example123
  uri: /kubernetes_operators/k8sop_2example123
  drain:
    drainedResources: 3
    failedResources: 0
    totalResources: 10
  conditions:
  - type: Draining
    status: "True"
    reason: DrainInProgress
    message: "Drain initiated"
    lastTransitionTime: "2025-10-29T00:39:15Z"
    observedGeneration: 1
  - type: Ready
    status: "False"
    reason: Draining
    message: "KubernetesOperator is being deleted"
    lastTransitionTime: "2025-10-29T00:39:15Z"
    observedGeneration: 1
```

### Drain retrying after errors

```yaml
status:
  id: k8sop_2example123
  uri: /kubernetes_operators/k8sop_2example123
  drain:
    drainedResources: 9
    failedResources: 1
    totalResources: 10
    errors:
    - "failed to delete CloudEndpoint my-endpoint: HTTP 500: internal server error"
  conditions:
  - type: Draining
    status: "True"
    reason: DrainFailed
    message: "Drain encountered 1 errors, will retry"
    lastTransitionTime: "2025-10-29T00:39:15Z"
    observedGeneration: 1
  - type: Ready
    status: "False"
    reason: DrainFailed
    message: "Drain encountered 1 errors, will retry"
    lastTransitionTime: "2025-10-29T00:39:15Z"
    observedGeneration: 1
```

## Example KubernetesOperator

```yaml
apiVersion: ngrok.com/v1
kind: KubernetesOperator
metadata:
  name: ngrok-operator
  namespace: ngrok-operator
spec:
  description: Created by ngrok-operator
  metadata:
    owned-by: ngrok-operator
  binding:
    endpointSelectors:
    - "true"
    ingressEndpoint: kubernetes-binding-ingress.ngrok.io:443
    tlsSecretName: ngrok-operator-default-tls
  deployment:
    name: ngrok-operator
    namespace: ngrok-operator
    version: 0.23.0
  enabledFeatures:
  - ingress
  - gateway
  - bindings
  region: global
```
