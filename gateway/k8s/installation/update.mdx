---
title: How to Update the ngrok Kubernetes Operator
sidebarTitle: Updates & Upgrades
description: Learn how to update the ngrok Kubernetes Operator to the latest version using Helm, including Gateway API CRD updates.
---



Updating the ngrok Kubernetes Operator is a very simple and straight-forward process.
Before updating, it is always best to check which version of the ngrok Kubernetes Operator you are running
and compare it to the most recent version or the version you want to update to.
You can refer to the [Operator changelog](/gateway/k8s/changelog) to view what has changed since the
version you are running to be informed about the changes you are making by updating.

Releases are named after the `ngrok-operator` Helm chart version (`CHART` in `helm list`); the changelog lists image versions (`APP VERSION`). See [Releasing](/gateway/k8s/releasing).

<Warning title="Upgrading from 0.24 to 0.25">
Helm chart 0.25 has breaking changes: one access token replaces the API key and authtoken, and Helm values move under `ngrok` and `components`. Upgrade from `0.24.x` only, upgrade `ngrok-crds` to `0.5.x` first if you install it separately, and don't use `--reuse-values`. Follow the [0.25 upgrade guide](https://github.com/ngrok/ngrok-operator/blob/main/docs/upgrading-to-0.25.md).
</Warning>

<Steps titleSize="h2">
  <Step title="(Optional) Update Gateway API CRDs">
    If you're using the Gateway API CRDs, you might want to update them while updating the Operator.
    For the most up-to-date information about installing/updating these, it is best to refer directly to the
    Gateway API website.

    https://gateway-api.sigs.k8s.io/
  </Step>

  <Step title="Update your helm repo">
    Fetch all the latest updates for your helm repositories to pull down all of the latest ngrok Kubernetes Operator chart versions.

    ```bash
    helm repo update
    ```
  </Step>

  <Step title="(optional) Find a specific release">
    The following command will print out a list of all the available versions of the ngrok Kubernetes Operator chart including development releases.
    If you want to update to a specific release of the Operator instead of updating to the latest version, you can set the following variable to the
    version of the Helm chart (not the `APP VERSION`) you would like to install.

    This step is necessary if you plan on upgrading to a development version as helm will never install these versions for you unless you explicitly
    specify that you want to install a development version. Development versions are considered any version that does not follow the format `<major version>.<minor version>.<patch version>` such as `0.25.0-rc.1`.
    Many of the development versions of the ngrok Kubernetes Operator follow that format with `rc` standing for Release Candidate. These are early development builds before an official release
    and may contain features that have not been fully implemented or bugs that have not been identified through testing.

    ```bash
    helm search repo ngrok/ngrok-operator --versions --devel
    ```

    ```bash
    export OPERATOR_CHART_VERSION=0.25.0
    ```
  </Step>

  <Step title="(Optional) Update the ngrok CRDs">
    If you installed `ngrok/ngrok-crds` separately (`installCRDs=false`), upgrade it first, to the version your target chart lists under `dependencies`:

    ```bash
    helm show chart ngrok/ngrok-operator --version $OPERATOR_CHART_VERSION
    ```

    ```bash
    export CRDS_CHART_VERSION=0.5.0
    helm upgrade ngrok-crds ngrok/ngrok-crds --version $CRDS_CHART_VERSION
    ```
  </Step>

  <Step title="Update the Operator with Helm">
    Set the following variables to the name and namespace of your Operator installation.
    You can check this with `helm list -A` if you did not use the following defaults.

    ```bash
    export OPERATOR_NAME=ngrok-operator
    export OPERATOR_NAMESPACE=ngrok-operator
    ```

    <Tabs>
    	<Tab title="Latest Release">
    	```bash
    	helm upgrade $OPERATOR_NAME ngrok/ngrok-operator \
    	--namespace $OPERATOR_NAMESPACE \
    	--reuse-values
    	```
    	</Tab>
    	<Tab title="Specific Release">
    	```bash
    	helm upgrade $OPERATOR_NAME ngrok/ngrok-operator \
    	--namespace $OPERATOR_NAMESPACE \
    	--version $OPERATOR_CHART_VERSION \
    	--reuse-values
    	```
    	</Tab>
    	<Tab title="From 0.24 to 0.25">
    	```bash
    	helm upgrade $OPERATOR_NAME ngrok/ngrok-operator \
    	--namespace $OPERATOR_NAMESPACE \
    	--version 0.25.0 \
    	--values path/to/your-values.yaml
    	```
    	</Tab>
    </Tabs>


    <Note>
    The --reuse-values flag will tell Helm to reuse any values you used in your last install/upgrade.
    You can change them or add new values by chaining --set flags just like when installing the Operator.
    </Note>
  </Step>
</Steps>
