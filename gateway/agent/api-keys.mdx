sidebarTitle: API Keys

---

The ngrok agent contains a [complete CLI for the ngrok API](/gateway/agent/cli-api/).

To use it, [create an API key on your ngrok dashboard](https://dashboard.ngrok.com/api-keys) and then run:

```bash
ngrok config add-api-key <API_KEY>
```

After you add the API key, try querying your list of domains or online endpoints:

```bash
ngrok api endpoints list
ngrok api reserved-domains list
```
