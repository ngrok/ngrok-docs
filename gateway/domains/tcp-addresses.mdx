## TCP Addresses

TCP Addresses enable you to create public [TCP Endpoints](/gateway/endpoints/tcp/) on a fixed address.
TCP Addresses are a host and port tuple, for example `1.tcp.eu.ngrok.io:12345`.

You can manage TCP Addresses on your [ngrok dashboard](https://dashboard.ngrok.com/tcp-addresses) or via the [ngrok API](#api).

## Public endpoint creation

A TCP Address's primary responsibility is to enable you to create public TCP endpoints with a hostname and port matching the address.
These are called "matching endpoints."
For example, after you create the TCP Address `1.tcp.jp.ngrok.io:12345`, you can create the Endpoint `tcp://1.tcp.jp.ngrok.io:12345`.

You can only create TCP endpoints on TCP Addresses.
To create other endpoint types, create a [Domain](/gateway/domains/).

## Address assignment

ngrok randomly assigns the hostname and port of the TCP Address when you create it, after which they don't change.
You can't choose the hostname or port.
If you delete a TCP Address, there's no way to provision the same one again.
You can manage TCP Addresses via the dashboard and the API.

The port of your TCP Address is uniquely assigned to your account, but other ports on that same hostname may be assigned to other accounts.
While the hostname and port of a TCP Address are fixed, they don't have static IPs.

## Global Load Balancer

The [global load balancer](/gateway/domains/global-load-balancer) doesn't support TCP Addresses.

You must select a [Point of Presence](/gateway/points-of-presence) when you create a TCP Address.
Connections to matching TCP Endpoints on a TCP Address always route to the TCP Address's point of presence, no matter where those connections originated in the world.

You can create Agent Endpoints from an agent connected to a different point of presence than the matching TCP Address.
For example, the following agent configuration connects to the Japan point of presence and still works properly with a TCP Address in the EU point of presence:

```yaml
version: 3
agent:
  connect_url: connect.jp.ngrok-agent.com:443
endpoints:
  - name: rdp
    url: tcp://1.tcp.eu.ngrok.io:12345
    upstream:
      url: 3389
```

## TCP Addresses pricing

TCP Addresses are available on the Hobbyist and Pay-as-you-go plans.
Both plans include 1 TCP Address.
Each additional address is billed at $0.005 per hour, which you can pay for with the usage credit included in your plan.

Pay-as-you-go accounts can reserve up to 100 TCP Addresses.
[Contact ngrok](https://ngrok.com/contact) if you need more.

TCP Addresses aren't available on the free plan.
Free accounts can create TCP endpoints on randomly assigned addresses after [adding a valid payment method](https://dashboard.ngrok.com/settings#id-verification)—see [TCP endpoint pricing](/gateway/endpoints/tcp/#tcp-endpoint-pricing).
