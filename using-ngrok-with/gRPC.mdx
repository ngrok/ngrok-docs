---
title: Using ngrok with gRPC
sidebarTitle: gRPC
description: Put a gRPC service online with ngrok by forwarding over HTTP/2 from an HTTPS endpoint, or by using a TCP endpoint instead.
---

Since gRPC uses HTTP/2, you may need to set the [upstream protocol](/gateway/agent/config/v3/#upstream) to `http2` in your agent configuration file when forwarding a gRPC endpoint:

```yaml
version: 3
endpoints:
  - name: grpc
    url: https://your-domain.ngrok.app
    upstream:
      url: 80
      protocol: http2
```

Then start the endpoint with `ngrok start grpc`.

This works with other ngrok features like custom domains and ports.

This [Stack Overflow user](https://stackoverflow.com/a/59555606/7282727) also reports that forwarding to gRPC services works using a [TCP endpoint](/gateway/endpoints/tcp/).
