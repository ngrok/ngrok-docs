## Why does ngrok return ERR_NGROK_6024?

ngrok displays this page to prevent abuse.
Visitors to your site only see it once.
ngrok shows it only for `GET` requests that send a browser `User-Agent` header, including `fetch` calls from browser JavaScript.
WebSocket connections and non-browser clients don't see it.
If you're attempting to access an endpoint programmatically and are still encountering this error, you can bypass the interstitial page.

## How do I fix ERR_NGROK_6024?

- Set and send an ngrok-skip-browser-warning request header with any value.
- Or, set and send a custom/non-standard browser User-Agent request header.
- Or, [upgrade](https://dashboard.ngrok.com/billing) to any paid ngrok account.

For more information and examples, see the interstitial explanation [here](/pricing-limits/free-plan-limits#removing-the-interstitial-page).

If you're the administrator for this account, and none of these steps work for you or you have more questions, email [support@ngrok.com](mailto:support@ngrok.com?subject=Help%20with%20ERR_NGROK_6024).
