This guide walks you through using ngrok to receive Mux webhooks on your localhost app.

By integrating ngrok with Mux, you can:

- Develop and test Mux webhooks locally without deploying to a public environment or setting up HTTPS.
- Inspect and troubleshoot requests from Mux in real time via the inspection UI and API.
- Modify and replay Mux webhook requests with a single click instead of reproducing events manually in your Mux account.
- Secure your app with Mux webhook validation provided by ngrok.
  Invalid requests are blocked by ngrok before reaching your app.

## What you'll need

- An [ngrok account](https://ngrok.com/signup) and your [authtoken](https://dashboard.ngrok.com/get-started/your-authtoken).
- The [ngrok agent](https://ngrok.com/download) installed.
- [Node.js](https://nodejs.org/) installed (for the sample app, or use your own app).
- A Mux account.

<Steps titleSize="h2">
  <Step title="Start your app">

    For this tutorial, you can use the [sample Node.js app on GitHub](https://github.com/ngrok/ngrok-webhook-nodejs-sample).

    To install the sample, run the following in a terminal:

    ```bash
    git clone https://github.com/ngrok/ngrok-webhook-nodejs-sample.git
    cd ngrok-webhook-nodejs-sample
    npm install
    ```

    Then start the app:

    ```bash
    npm start
    ```

    The app runs on port 3000 by default.

    You can confirm it's running by visiting `http://localhost:3000`.
    The app logs request headers and body in the terminal and shows a message in the browser.
  </Step>

  <Step title="Expose your app with ngrok">

    Once your app is running locally, you're ready to put it online securely using ngrok.

    - Copy [your ngrok authtoken](https://dashboard.ngrok.com/get-started/your-authtoken) from the dashboard.

    <Tip>
      The ngrok agent uses your authtoken to authenticate when you start a tunnel.
    </Tip>

    - Start ngrok:

      ```bash
      ngrok http 3000
      ```

    - Copy the URL ngrok displays.
      Your app is now exposed at that URL for use with Mux.
  </Step>

  <Step title="Configure Mux to send webhooks">

    Follow [Mux's documentation for listening for webhooks](https://www.mux.com/docs/guides/listen-for-webhooks), select your environment, and set the following:

    - **URL to notify**: your ngrok URL (for example, `https://1a2b-3c4d-5e6f-7g8h-9i0j.ngrok.app`).

    ### Run webhooks with Mux and ngrok

    Mux sends different request body contents depending on the event.
    To trigger a call, create an event in your environment, such as a new asset.

    Confirm your localhost app receives event notifications and logs both headers and body in the terminal.

## Secure webhook requests

ngrok can verify that incoming requests are from your Mux webhook so only that traffic reaches your app.

<Note>
  Webhook verification is limited to 500 validations per month on free accounts.
  If you need more, you can upgrade to Hobbyist or Pay-as-you-go.
  See [TPU Pricing](/pricing-limits/traffic-policy-unit-pricing/) for details.
</Note>

To add verification:

- In [Mux](https://www.mux.com/), go to **Settings** and **Webhooks**.
- On the **Webhooks** tab, click **Show Signing Secret** for your webhook and copy the value.
- Create a Traffic Policy file named `mux_policy.yml`.
  Replace `{your signing secret}` with the value you copied:

  ```yaml
  on_http_request:
    - actions:
        - type: verify-webhook
          config:
            provider: mux
            secret: "{your signing secret}"
  ```

- Restart ngrok with the policy file:

  ```bash
  ngrok http 3000 --traffic-policy-file mux_policy.yml
  ```

- Create a new asset in Mux to trigger the webhook.

Your app should receive the request and log it in the terminal.
