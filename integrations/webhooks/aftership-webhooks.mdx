This guide explains how to use ngrok to receive AfterShip webhooks on your localhost app.

By integrating ngrok with AfterShip, you can:

- Develop and test AfterShip webhooks locally without deploying to a public environment or setting up HTTPS.
- Inspect and troubleshoot requests from AfterShip in real time via the inspection UI and API.
- Modify and replay AfterShip webhook requests with a single click instead of reproducing events manually in your AfterShip account.
- Secure your app with AfterShip webhook validation provided by ngrok.
  Invalid requests are blocked by ngrok before reaching your app.

## What you'll need

- An [ngrok account](https://ngrok.com/signup) and your [authtoken](https://dashboard.ngrok.com/get-started/your-authtoken).
- The [ngrok agent](https://ngrok.com/download) installed.
- [Node.js](https://nodejs.org/) installed (for the sample app, or use your own app).
- An AfterShip account.

## 1. Start your app

For this tutorial, you can use the [sample Node.js app on GitHub](https://github.com/ngrok/ngrok-webhook-nodejs-sample).

To install the sample, run the following in a terminal:

```bash
git clone https://github.com/ngrok/ngrok-webhook-nodejs-sample.git
cd ngrok-webhook-nodejs-sample
npm install
```

Then start the app:

```bash
npm start
```

The app runs on port 3000 by default.

You can confirm it's running by visiting `http://localhost:3000`.
The app logs request headers and body in the terminal and shows a message in the browser.

## 2. Expose your app with ngrok

Once your app is running locally, you're ready to put it online securely using ngrok.

- Copy [your ngrok authtoken](https://dashboard.ngrok.com/get-started/your-authtoken) from the dashboard.

<Tip>
  The ngrok agent uses your authtoken to authenticate when you start a tunnel.
</Tip>

- Start ngrok:

  ```bash
  ngrok http 3000
  ```

- Copy the URL ngrok displays.
  Your app is now exposed at that URL for use with AfterShip.

## 3. Configure AfterShip to send webhooks

Follow [AfterShip's documentation for creating a webhook](https://www.aftership.com/docs/tracking/webhook/webhook-overview), and set the following:

- **Webhook URL**: your ngrok URL (for example, `https://1a2b-3c4d-5e6f-7g8h-9i0j.ngrok.app`).

### Run webhooks with AfterShip and ngrok

After you add the webhook, AfterShip sends POST requests to your app through ngrok as shipment statuses change.

To trigger a webhook call, add a shipment with a tracking number in your AfterShip account. Confirm your app receives the notification and logs the headers and body in the terminal.

## Secure webhook requests

ngrok can verify that incoming requests are from your AfterShip webhook so only that traffic reaches your app.

<Note>
  Webhook verification is limited to 500 validations per month on free accounts.
  If you need more, you can upgrade to Hobbyist or Pay-as-you-go.
  See [TPU Pricing](/pricing-limits/traffic-policy-unit-pricing/) for details.
</Note>

To add verification:

- Create a Traffic Policy file named `aftership_policy.yml`.
  Replace `{your secret}` with the **Webhook secret** from your AfterShip webhook:

  ```yaml
  on_http_request:
    - actions:
        - type: verify-webhook
          config:
            provider: aftership
            secret: "{your secret}"
  ```

- Restart ngrok with the policy file:

  ```bash
  ngrok http 3000 --traffic-policy-file aftership_policy.yml
  ```

- Create a new shipment in your AfterShip account to trigger a delivery.

Your app should receive the request and log it in the terminal.
