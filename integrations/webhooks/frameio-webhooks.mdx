This guide walks you through using ngrok to receive Frame.io webhooks on your localhost app.

By integrating ngrok with Frame.io, you can:

- Develop and test Frame.io webhooks locally without deploying to a public environment or setting up HTTPS.
- Inspect and troubleshoot requests from Frame.io in real time via the inspection UI and API.
- Modify and replay Frame.io webhook requests with a single click instead of reproducing events manually in your Frame.io account.
- Secure your app with Frame.io webhook validation provided by ngrok.
  Invalid requests are blocked by ngrok before reaching your app.

## What you'll need

- An [ngrok account](https://ngrok.com/signup) and your [authtoken](https://dashboard.ngrok.com/get-started/your-authtoken).
- The [ngrok agent](https://ngrok.com/download) installed.
- [Node.js](https://nodejs.org/) installed (for the sample app, or use your own app).
- A Frame.io account.

<Steps>
  <Step title="Start your app">

    For this tutorial, you can use the [sample Node.js app on GitHub](https://github.com/ngrok/ngrok-webhook-nodejs-sample).

    To install the sample, run the following in a terminal:

    ```bash
    git clone https://github.com/ngrok/ngrok-webhook-nodejs-sample.git
    cd ngrok-webhook-nodejs-sample
    npm install
    ```

    Then start the app:

    ```bash
    npm start
    ```

    The app runs on port 3000 by default.

    You can confirm it's running by visiting `http://localhost:3000`.
    The app logs request headers and body in the terminal and shows a message in the browser.
  </Step>

  <Step title="Expose your app with ngrok">

    Once your app is running locally, you're ready to put it online securely using ngrok.

    - Copy [your ngrok authtoken](https://dashboard.ngrok.com/get-started/your-authtoken) from the dashboard.

    <Tip>
      The ngrok agent uses your authtoken to authenticate when you start a tunnel.
    </Tip>

    - Start ngrok:

      ```bash
      ngrok http 3000
      ```

    - Copy the URL ngrok displays.
      Your app is now exposed at that URL for use with Frame.io.
  </Step>

  <Step title="Configure Frame.io to send webhooks">

    Follow [Frame.io's webhooks documentation](https://next.developer.frame.io/platform/docs/guides/webhooks) to create a webhook, and set the following:

    - **URL**: your ngrok URL (for example, `https://1a2b-3c4d-5e6f-7g8h-9i0j.ngrok.app`).
    - **Events**: choose which events trigger the webhook (for this example, the project created event).

    ### Run webhooks with Frame.io and ngrok

    After you create the webhook, Frame.io sends POST requests to your app when the events you chose occur.
    The request body varies by event.

    To trigger a call, create a new project in Frame.io, then confirm your localhost app logs the request headers and body in the terminal.

    You can also review the webhook logs in Frame.io to compare what Frame.io sent with what your app received.

  </Step>
</Steps>
## Secure webhook requests

ngrok can verify that incoming requests are from your Frame.io webhook so only that traffic reaches your app.

<Note>
  Webhook verification is limited to 500 validations per month on free accounts.
  If you need more, you can upgrade to Hobbyist or Pay-as-you-go.
  See [TPU Pricing](/pricing-limits/traffic-policy-unit-pricing/) for details.
</Note>

To add verification:

- Copy the **Secret** for your webhook from Frame.io (see [Frame.io's webhooks documentation](https://next.developer.frame.io/platform/docs/guides/webhooks)).
- Create a Traffic Policy file named `frameio_policy.yml`.
  Replace `{your webhook secret}` with the value you copied:

  ```yaml
  on_http_request:
    - actions:
        - type: verify-webhook
          config:
            provider: frameio
            secret: "{your webhook secret}"
  ```

- Restart ngrok with the policy file:

  ```bash
  ngrok http 3000 --traffic-policy-file frameio_policy.yml
  ```

- Create a new project in Frame.io to trigger the webhook.

Your app should receive the request and log it in the terminal.
