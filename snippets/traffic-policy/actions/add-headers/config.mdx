

## Configuration reference

The [Traffic Policy](/gateway/traffic-policy/) configuration
reference for this action.

### Supported phases

`on_http_request`, `on_http_response`

### Type

`add-headers`

### Configuration fields

<Config>
	<ConfigField title="headers" type="object" cel={true}>
		<p>Map of header key to header value to be added.</p>
		<p>Minimum `1`, Maximum `10`.</p>
		<p>
			Supports [CEL Interpolation](/gateway/traffic-policy/how-it-works#cel-interpolation)
			in header values.
		</p>
	</ConfigField>
</Config>
