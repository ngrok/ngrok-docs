<Info>
There's no dedicated ngrok Kubernetes Operator example for this configuration.
To create TLS endpoints with the Operator, use a `LoadBalancer` Service, a Gateway API `TLSRoute`, or an `AgentEndpoint` with a `tls://` URL.
See [TLS routing](/gateway/k8s/guides/how-to/tls-routing/) and [endpoint types](/gateway/k8s/guides/endpoint-types/).
</Info>
