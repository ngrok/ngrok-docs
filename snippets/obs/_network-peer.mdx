| Name | Type | Description |
|---|---|---|
| id | string | Unique peer identifier with the npr_ prefix. It is stable only for the life of the session. |
| uri | string | URI of this peer within its network. |
| network.id | string | a resource identifier |
| network.uri | string | a uri for locating a resource |
| ips.id | string | Unique assignment identifier with the nip_ prefix. |
| ips.uri | string | URI of this assignment within its network. |
| ips.address | string | Reserved IPv4 or IPv6 address. |
| metadata | Map&lt;string, string&gt; | Facts about the peer's session as string key-value pairs. |
| connected_at | string | Time in RFC 3339 format when ngrok first recorded the session. |
