| Name | Type | Description |
|---|---|---|
| ips.id | string | Unique assignment identifier with the nip_ prefix. |
| ips.uri | string | URI of this assignment within its network. |
| ips.created_at | string | Creation time in RFC 3339 format. |
| ips.address | string | Reserved IPv4 or IPv6 address. |
| ips.name | string | Optional DNS label, unique per address family within the network. Names are case-insensitive and returned in lowercase. |
| ips.type | string | Assignment type. Assignments created through this API are static. |
| ips.peer.id | string | a resource identifier |
| ips.peer.uri | string | a uri for locating a resource |
| ips.expires_at | string | Expiration time in RFC 3339 format, or null for a static assignment. |
