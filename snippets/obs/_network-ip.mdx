| Name | Type | Description |
|---|---|---|
| id | string | Unique assignment identifier with the nip_ prefix. |
| uri | string | URI of this assignment within its network. |
| created_at | string | Creation time in RFC 3339 format. |
| address | string | Reserved IPv4 or IPv6 address. |
| name | string | Optional DNS label, unique per address family within the network. Names are case-insensitive and returned in lowercase. |
| type | string | Assignment type. Assignments created through this API are static. |
| peer.id | string | a resource identifier |
| peer.uri | string | a uri for locating a resource |
| expires_at | string | Expiration time in RFC 3339 format, or null for a static assignment. |
