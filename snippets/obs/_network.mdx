| Name | Type | Description |
|---|---|---|
| id | string | Unique network identifier with the net_ prefix. |
| uri | string | URI of this network resource. |
| created_at | string | Creation time in RFC 3339 format. |
| description | string | Optional human-readable description. |
| metadata | Map&lt;string, string&gt; | User-defined metadata as string key-value pairs. |
| ipv4_cidr | string | Canonical IPv4 CIDR. Immutable after creation. |
| ipv6_cidr | string | Canonical IPv6 CIDR. Immutable after creation. |
| search_domain | string | DNS suffix for named assignments. Immutable after creation. The internal and ngrok.direct domains and their subdomains are reserved. |
