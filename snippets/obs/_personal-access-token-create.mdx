| Name | Type | Description |
|---|---|---|
| description | string | human-readable description of this token. Optional, max 255 bytes. |
| expires_at | string | optional expiration time for this token. If unset the token does not expire. |
| scopes | List&lt;string&gt; | scopes this token can use, e.g. `["endpoints:read"]`. Each must be a scope you can grant. |
