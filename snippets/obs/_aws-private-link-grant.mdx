| Name | Type | Description |
|---|---|---|
| id | string | Unique identifier with the plgrt_ prefix. |
| uri | string | URI of this AWS Private Link Grant resource. |
| created_at | string | Creation time in RFC 3339 format. |
| created_by | string | ID of the user or bot that created the grant. |
| private_link_id | string | ID of the AWS Private Link the endpoint is admitted to. |
| allowed_account_id | string | ID of the AWS Private Link Allowed Account that admitted the endpoint's owner. |
| aws_region | string | AWS region the endpoint was created in. Must be one of the link's regions. |
| vpc_endpoint_id | string | The consumer's VPC endpoint ID, which starts with vpce-. |
| consumer_aws_account_id | string | The twelve-digit AWS account that owns the endpoint, as AWS reports it. |
