| Name | Type | Description |
|---|---|---|
| agents.id | string | unique identifier for this Agent |
| agents.uri | string | URI of this Agent API resource |
| agents.name | string | human-readable name of this Agent, generated by the server if none is given. max 255 bytes. |
| agents.metadata | string | arbitrary user-defined machine-readable data of this Agent. optional, max 4096 bytes. |
| agents.created_at | string | timestamp when the Agent was created, RFC 3339 format |
| agents.principal.id | string | a resource identifier |
| agents.principal.uri | string | a uri for locating a resource |
| agents.credentials.id | string | a resource identifier |
| agents.credentials.uri | string | a uri for locating a resource |
| agents.deleted_at | string | timestamp when the Agent was soft-deleted, RFC 3339 format. Omitted if the Agent is live. |
| agents.previous_agent_id | string | ID of the retired Agent that this Agent replaced, if any |
| agents.account_id | string | ID of the account that owns this Agent (`ac_`-prefixed) |
| agents.durable | boolean | true for a registered Agent, which keeps its ID while it is offline. A durable: false Agent is either a live session with no record, whose id is the tunnel session ID, or an unregistered Agent, which has deleted_at set. Either is listed only while it is online. |
| agents.status | string | connected while the Agent has a live session, otherwise disconnected. Omitted where live sessions are not read. |
| agents.started_at | string | timestamp when the current session started, RFC 3339 format. Omitted when disconnected. |
| agents.region | string | region of the current session. Omitted when disconnected. |
| agents.ip | string | observed public IP address of the current session. Omitted when disconnected. |
| agents.last_seen | string | timestamp when the Agent's most recent session ended, RFC 3339 format. Omitted if it never disconnected. |
| agents.agent_version | string | version of the agent, as it reported at its last connect. Omitted until the first connect. |
| agents.client_type | string | kind of client, for example `ngrok-agent`. Omitted until the first connect. |
| agents.os | string | operating system of the agent, for example `linux`. Omitted until the first connect. |
| agents.arch | string | CPU architecture of the agent, for example `amd64`. Omitted until the first connect. |
| agents.capabilities.stop.supported | boolean | true if the agent supports the action |
| agents.capabilities.stop.unsupported_reason | string | why the agent does not support the action. Omitted if it does, or gave no reason. |
| agents.capabilities.restart.supported | boolean | true if the agent supports the action |
| agents.capabilities.restart.unsupported_reason | string | why the agent does not support the action. Omitted if it does, or gave no reason. |
| agents.capabilities.update.supported | boolean | true if the agent supports the action |
| agents.capabilities.update.unsupported_reason | string | why the agent does not support the action. Omitted if it does, or gave no reason. |
| agents.deprecation_warning.next_min_version | string | the lowest agent version supported from the deadline on |
| agents.deprecation_warning.deadline | string | timestamp when versions below next_min_version stop being supported, RFC 3339 format. Omitted if there is no date. |

| next_page_uri | string | URI of the next page, or null if there is no next page. A full last page can link to an empty page. |
