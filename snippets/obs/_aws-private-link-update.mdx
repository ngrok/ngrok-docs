| Name | Type | Description |
|---|---|---|
| id | string | Unique identifier with the plinko_ prefix. |
| name | string | Name of the link. Unique within the account and never sent to AWS. |
| description | string | Optional human-readable description, max 255 bytes. |
| metadata | Map&lt;string, string&gt; | User-defined metadata as string key-value pairs. |
| regions | List&lt;string&gt; | AWS regions, such as us-east-2, the link is reachable through. Omitted leaves the set alone. A present list replaces it, and an empty list clears it. Removing a region revokes the grants in it. |
| hostnames | List&lt;string&gt; | Hostnames or wildcards the link advertises to its consumers. Stored lowercase. Omitted leaves the set alone. A present list replaces it, and an empty list clears it. |
