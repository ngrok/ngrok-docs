| Name | Type | Description |
|---|---|---|
| api_key | string | Datadog API key to use. |
| ddtags | string | Tags to send with the event. |
| service | string | Service name to send with the event. |
| ddsite | string | Datadog site to send event to. |
| intake_host | string | Hostname of a Datadog-compatible log intake to send events to instead of a Datadog site. Events go to the /api/v2/logs path on this host over HTTPS. Set either this or ddsite, not both. |
| auth_scheme | string | How to send the API key. dd_api_key (the default) sends the DD-API-KEY header. bearer sends an Authorization: Bearer header. |
