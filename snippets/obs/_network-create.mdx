| Name | Type | Description |
|---|---|---|
| description | string | Optional human-readable description. |
| metadata | Map&lt;string, string&gt; | User-defined metadata as string key-value pairs. |
| ipv4_cidr | string | Private IPv4 CIDR. If omitted, the API allocates an RFC 1918 /16. |
| ipv6_cidr | string | Private IPv6 CIDR. If omitted, the API allocates a /56 within the account's unique-local /48. |
| search_domain | string | DNS suffix without a leading dot. Defaults to the network ID, with its underscore replaced by a hyphen, under ngrok.network. |
