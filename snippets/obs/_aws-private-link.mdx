| Name | Type | Description |
|---|---|---|
| id | string | Unique identifier with the plinko_ prefix. |
| uri | string | URI of this AWS Private Link resource. |
| created_at | string | Creation time in RFC 3339 format. |
| updated_at | string | Last update time in RFC 3339 format. |
| name | string | Name of the link. Unique within the account and never sent to AWS. |
| description | string | Optional human-readable description, max 255 bytes. |
| metadata | Map&lt;string, string&gt; | User-defined metadata as string key-value pairs. |
| created_by | string | ID of the user or bot that created the link. |
| last_updated_by | string | ID of the user or bot that last changed the link. |
| regions | List&lt;string&gt; | AWS regions, such as us-east-2, the link is reachable through. |
| service_names | Map&lt;string, string&gt; | Read-only. Each region in regions mapped to the ngrok endpoint service name a consumer in that region connects to. |
| hostnames | List&lt;string&gt; | Hostnames or wildcards the link advertises to its consumers. Stored lowercase. |
