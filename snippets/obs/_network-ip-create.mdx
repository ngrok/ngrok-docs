| Name | Type | Description |
|---|---|---|
| network_id | string | Network that owns the assignment. |
| address | string | Requested address within the network's CIDR. If omitted, the API allocates an address. |
| ip_version | uint32 | Address family: 4 or 6. Required without an address. If both are present, they must match. |
| name | string | Optional DNS label, unique per address family within the network. Names are case-insensitive and returned in lowercase. |
