| Name | Type | Description |
|---|---|---|
| id | string | unique identifier for this Agent |
| uri | string | URI of this Agent API resource |
| name | string | human-readable name of this Agent, generated by the server if none is given. max 255 bytes. |
| metadata | string | arbitrary user-defined machine-readable data of this Agent. optional, max 4096 bytes. |
| created_at | string | timestamp when the Agent was created, RFC 3339 format |
| principal.id | string | a resource identifier |
| principal.uri | string | a uri for locating a resource |
| credentials.id | string | a resource identifier |
| credentials.uri | string | a uri for locating a resource |
| deleted_at | string | timestamp when the Agent was soft-deleted, RFC 3339 format. Omitted if the Agent is live. |
| previous_agent_id | string | ID of the retired Agent that this Agent replaced, if any |
| account_id | string | ID of the account that owns this Agent (`ac_`-prefixed) |
| durable | boolean | true for a registered Agent, which keeps its ID while it is offline. A durable: false Agent is either a live session with no record, whose id is the tunnel session ID, or an unregistered Agent, which has deleted_at set. Either is listed only while it is online. |
| status | string | connected while the Agent has a live session, otherwise disconnected. Omitted where live sessions are not read. |
| started_at | string | timestamp when the current session started, RFC 3339 format. Omitted when disconnected. |
| region | string | region of the current session. Omitted when disconnected. |
| ip | string | observed public IP address of the current session. Omitted when disconnected. |
| last_seen | string | timestamp when the Agent's most recent session ended, RFC 3339 format. Omitted if it never disconnected. |
| agent_version | string | version of the agent, as it reported at its last connect. Omitted until the first connect. |
| client_type | string | kind of client, for example `ngrok-agent`. Omitted until the first connect. |
| os | string | operating system of the agent, for example `linux`. Omitted until the first connect. |
| arch | string | CPU architecture of the agent, for example `amd64`. Omitted until the first connect. |
| capabilities.stop.supported | boolean | true if the agent supports the action |
| capabilities.stop.unsupported_reason | string | why the agent does not support the action. Omitted if it does, or gave no reason. |
| capabilities.restart.supported | boolean | true if the agent supports the action |
| capabilities.restart.unsupported_reason | string | why the agent does not support the action. Omitted if it does, or gave no reason. |
| capabilities.update.supported | boolean | true if the agent supports the action |
| capabilities.update.unsupported_reason | string | why the agent does not support the action. Omitted if it does, or gave no reason. |
| deprecation_warning.next_min_version | string | the lowest agent version supported from the deadline on |
| deprecation_warning.deadline | string | timestamp when versions below next_min_version stop being supported, RFC 3339 format. Omitted if there is no date. |
