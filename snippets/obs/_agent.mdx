| Name | Type | Description |
|---|---|---|
| id | string | unique identifier for this Agent |
| uri | string | URI of this Agent API resource |
| name | string | human-readable name of this Agent, generated by the server if none is given. max 255 bytes. |
| metadata | string | arbitrary user-defined machine-readable data of this Agent. optional, max 4096 bytes. |
| created_at | string | timestamp when the Agent was created, RFC 3339 format |
| principal.id | string | a resource identifier |
| principal.uri | string | a uri for locating a resource |
| credentials.id | string | a resource identifier |
| credentials.uri | string | a uri for locating a resource |
| deleted_at | string | timestamp when the Agent was soft-deleted, RFC 3339 format. Omitted if the Agent is live. |
| previous_agent_id | string | ID of the retired Agent that this Agent replaced, if any |
| account_id | string | ID of the account that owns this Agent (`ac_`-prefixed) |
