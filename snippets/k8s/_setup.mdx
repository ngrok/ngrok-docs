### Add the ngrok Helm chart

```bash
helm repo add ngrok https://charts.ngrok.com
helm repo update
```

<Note>
Whenever you want to update the Operator or install a new version, you must run `helm repo update` to fetch the latest charts.
</Note>

### Get your ngrok access token

Create an [access token](https://dashboard.ngrok.com/access-tokens) with permission to start tunnels and manage endpoints, domains, reserved TCP addresses, IP policies, and the Kubernetes Operator registration.

The ngrok Kubernetes Operator provisions it as a Kubernetes secret, then uses it both to create tunnels and to manage resources via the [ngrok API](/api/).

<Tabs>
  <Tab title="Linux">

```bash
export NGROK_ACCESS_TOKEN=your copied access token goes here
```

  </Tab>
  <Tab title="PowerShell">

```powershell
$env:NGROK_ACCESS_TOKEN = "your copied access token goes here"
```

  </Tab>
</Tabs>
