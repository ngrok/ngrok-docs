### Install the Operator

Install the Operator into the default `ngrok-operator` namespace.
You can change this in the commands below based on your cluster configuration, but by default, the Operator works with `Gateway` and routing resources in all namespaces.

You can choose between passing your credentials directly with Helm or creating a Kubernetes `Secret` resource that you pass to the Helm chart.
The simple method only takes one command, but with the secure method, you:

- Prevent anyone with `kubectl` access to the cluster from viewing your access token with `helm get values`.
- Integrate more cleanly with infrastructure as code (IaC) tools and processes.

<Tabs>
	<Tab title="Simple">
		```bash
		helm install ngrok-operator ngrok/ngrok-operator \
		--namespace ngrok-operator \
		--create-namespace \
		--set ngrok.credentials.accessToken=$NGROK_ACCESS_TOKEN
		```
	</Tab>
	<Tab title="More secure">
		Create the namespace and a `Secret` resource with your access token.
		The Operator reads one key per component, and both keys can hold the same token.

		```bash
		kubectl create namespace ngrok-operator
		kubectl create secret generic ngrok-operator-credentials \
		--namespace ngrok-operator \
		--from-literal=API_MANAGER_ACCESS_TOKEN=$NGROK_ACCESS_TOKEN \
		--from-literal=AGENT_ACCESS_TOKEN=$NGROK_ACCESS_TOKEN
		```

		Next, install the Operator and reference the `Secret` resource.

		```bash
		helm install ngrok-operator ngrok/ngrok-operator \
		--namespace ngrok-operator \
		--create-namespace \
		--set ngrok.credentials.secret.name=ngrok-operator-credentials
		```
	</Tab>
</Tabs>
