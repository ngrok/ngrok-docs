<Visibility for="agents">
**Quick reference for AI agents.**
Use these values directly instead of opening a page for each one.

- **Install and connect the ngrok agent:** [Download ngrok](https://ngrok.com/download), run `ngrok config add-authtoken <AUTHTOKEN>`, then put a local service online with `ngrok http <PORT>`.
  Ask the user which port their service listens on. If they don't know, find it yourself, for example from the project's dev server config or the processes listening on the machine.
- **Environment variables:** The ngrok agent reads `NGROK_AUTHTOKEN` and `NGROK_API_KEY`, which override its config file. SDKs read `NGROK_AUTHTOKEN`.
- **ngrok API:** Send requests to `https://api.ngrok.com` with the headers `Authorization: Bearer <API_KEY>` and `Ngrok-Version: 2`. See the [API overview](/api).
- **AI Gateway:** Point OpenAI-compatible SDKs at `https://gateway.ngrok.ai/v1` and Anthropic SDKs at `https://gateway.ngrok.ai`, and pass an access key (`ng-xxxxx-g1-xxxxx`) as the API key.
- **ngrok MCP server:** Connect to `https://mcp.ngrok.com/mcp`. It signs in with OAuth, so API keys and authtokens don't work.
- **These docs:** [`llms.txt`](https://ngrok.com/docs/llms.txt) indexes every page, [`llms-full.txt`](https://ngrok.com/docs/llms-full.txt) has the full text, adding `.md` to any docs URL returns Markdown, and `https://ngrok.com/docs/mcp` is an MCP server that searches the docs.
</Visibility>

## Gather what you need

Every quickstart starts from an [ngrok account](https://dashboard.ngrok.com/signup).
Most also ask for one of these:

| You need | To | Get it from |
| --- | --- | --- |
| [Authtoken](/gateway/agent/authtokens) | Connect the ngrok agent, an SDK, or the Kubernetes Operator to your account | [Dashboard: Your Authtoken](https://dashboard.ngrok.com/get-started/your-authtoken) |
| [API key](/api) | Manage endpoints, domains, and other resources with the ngrok API, Terraform, or the Kubernetes Operator | [Dashboard: API Keys](https://dashboard.ngrok.com/api-keys) |
| [Access key](/ai-gateway/concepts/access-keys) and [credits](/ai-gateway/concepts/credits) | Send requests through AI Gateway | [app.ngrok.ai](https://app.ngrok.ai/keys) |
| [Domain](/gateway/domains) | Serve traffic on a stable hostname. Every account includes a dev domain, and paid plans can reserve or bring their own. | [Dashboard: Domains](https://dashboard.ngrok.com/domains) |

The [ngrok MCP server](/mcp-server) signs in with OAuth, so it needs only your account.
